# DH-TALK V2 Acceptance Criteria

## 1. 환자 보드

- 예약표를 붙여넣으면 오늘 환자 목록이 생성된다.
- 예약 없이 온 환자를 10초 이내에 수동 추가할 수 있다.
- 환자 이름, 예약 시간, 상태를 수정할 수 있다.
- 환자 순서를 바꿀 수 있다.
- 환자 상태를 `대기`, `진료중`, `완료`, `보류`, `노쇼`로 변경할 수 있다.
- 한 PC에서 변경한 환자 상태가 다른 PC에 실시간 반영된다.

## 2. 환자 선택과 매크로

- 환자 이름을 클릭하면 현재 선택 환자로 표시된다.
- 현재 선택 환자가 없으면 호출 매크로 전송을 막고 선택 안내를 표시한다.
- `{name}`이 선택 환자 이름으로 치환된다.
- 예: `{name}님 들어오세요.` → `홍길동님 들어오세요.`
- 사용자는 개인 매크로를 추가, 수정, 삭제, 순서 변경할 수 있다.
- 공통 매크로와 개인 매크로가 구분된다.

## 3. 호출 팝업

- 원장이 호출 매크로를 보내면 수신 PC에 팝업이 뜬다.
- 팝업은 확인/닫기 전까지 자동으로 사라지지 않는다.
- 팝업은 현재 작업창의 키보드 포커스를 빼앗지 않는다.
- 가능한 환경에서는 팝업이 화면 맨 앞에 표시된다.
- 소리는 기본 OFF다.
- 사용자 설정에서 소리를 ON으로 바꿀 수 있다.
- 여러 호출이 오면 닫히지 않은 호출이 유실되지 않는다.
- 확인/닫기 버튼을 누르면 해당 호출은 읽음/닫힘 상태가 된다.

## 4. 파일 전송

- 브라우저에서 파일을 선택해 업로드할 수 있다.
- 업로드 진행률이 표시된다.
- 업로드 완료 후 메시지에 파일 카드가 표시된다.
- 다른 사용자는 파일 카드에서 다운로드할 수 있다.
- 파일 카드에는 파일명, 크기, 업로드자, 업로드 시간이 표시된다.
- 허용되지 않은 확장자는 업로드되지 않는다.
- 제한 용량을 넘은 파일은 업로드되지 않는다.
- 만료된 파일은 다운로드되지 않는다.
- 외부 비로그인 사용자는 파일에 접근할 수 없다.

## 5. 보안/개인정보

- 로그인하지 않으면 앱에 접근할 수 없다.
- 환자 카드에는 진단명, 처방, 상담 내용, 전화번호, 주민번호 입력란이 없다.
- 운영 메모에는 민감정보 금지 안내가 표시된다.
- `.env`와 API 키는 GitHub에 커밋되지 않는다.
- Storage bucket은 공개 설정이 아니다.

## 6. 성능/사용성

- 초기 로딩 후 환자 상태 변경은 1초 내 다른 PC에 반영되는 것을 목표로 한다.
- 환자 추가, 선택, 호출까지 3클릭 이내로 가능해야 한다.
- 접수 직원이 환자 리스트를 빠르게 수정할 수 있어야 한다.
- 원장은 환자 이름 클릭 후 매크로 버튼 한 번으로 호출할 수 있어야 한다.
