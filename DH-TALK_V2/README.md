# DH-TALK V2

동행정신건강의학과 외래 운영용 실시간 환자 흐름 보드 및 호출 매크로 시스템.

## 방향 전환

기존 DH-TALK의 서버컴 기반 연결 구조는 병원 내부망, 방화벽, Windows 권한, 절전모드, IP 변경, 백신, 공유기 설정에 취약하다. V2는 서버컴을 제거하고 클라우드 실시간 웹앱 중심으로 전환한다.

```text
기존: 서버컴 기반 채팅/파일전송 프로그램
변경: 클라우드 실시간 환자 보드 + 이름삽입 매크로 호출기 + 선택적 파일 전송
```

## 핵심 목표

1. 병원 여러 PC가 같은 URL에 접속해 오늘 환자 보드를 실시간으로 공유한다.
2. 예약표를 쉽게 올리고 실제 내원 순서에 맞게 수동 수정한다.
3. 예약 없이 온 환자를 즉시 추가한다.
4. 환자 이름을 클릭하면 현재 선택 환자로 지정된다.
5. `{name}` 매크로가 선택 환자 이름으로 자동 치환된다.
6. 원장이 호출 매크로를 보내면 직원 PC에 비활성 always-on-top 팝업이 뜬다.
7. 팝업은 확인/닫기 버튼을 누르기 전까지 자동으로 사라지지 않는다.
8. 소리는 기본 OFF이며 직원별로 켤 수 있다.
9. 브라우저 기반 파일 전송을 지원하되 임시 전달 용도로 제한한다.

## P0 기능

- 클라우드 실시간 환자 보드
- 오늘 환자 리스트 붙여넣기/import
- 환자 수동 추가, 이름 수정, 삭제
- 환자 순서 변경
- 환자 상태 변경: `대기`, `진료중`, `완료`, `보류`, `노쇼`
- 환자 클릭 → 현재 선택 환자 지정
- `{name}` 매크로 치환
- 직원별 매크로 추가/수정/삭제/순서변경
- 원장 호출 → 직원 PC 팝업
- 팝업은 닫기 전까지 유지
- 팝업은 현재 작업창 포커스를 빼앗지 않음
- 소리 기본 OFF

## P1 기능

- 브라우저 파일 업로드/다운로드
- 파일 카드: 파일명, 크기, 업로드자, 업로드 시간, 다운로드, 삭제
- 파일 크기 제한
- 허용 확장자 제한
- 보관 기간 제한
- 파일 자동 삭제
- 호출 이력 및 읽음 확인
- 대기실 표시 화면

## P2 기능

- 카카오/SMS 연동
- EMR 연동
- 음성 호출
- 태블릿 키오스크
- 운영 통계
- 예약변경/노쇼 리콜 자동화

## 권장 기술 구조

```text
Web App: React + TypeScript + Vite
Realtime DB: Supabase 또는 Firebase
File Storage: Supabase Storage 또는 Firebase Storage
Desktop Notifier: Tauri 또는 Electron
Hosting: Vercel/Netlify/Supabase Hosting
```

## 개인정보 원칙

DH-TALK V2는 EMR이 아니다. 저장 범위는 외래 운영에 필요한 최소 정보로 제한한다.

저장 가능:

- 당일 환자 이름
- 예약 시간
- 대기 상태
- 호출 메시지
- 직원별 매크로
- 임시 파일 메타데이터

저장 금지:

- 주민번호
- 전화번호
- 진단명
- 처방
- 상담 내용
- 심리검사 결과
- 보험 정보
- EMR 기록
