# 작업 진행 상황 — 체스프렌즈 (Kids Chess)

> 광고·채팅·랜덤 온라인 상대·인앱 결제 유도가 없는 어린이용(6~12세) 체스 앱.
> "어린이가 좋아하는 UI + 체스의 정통성" 두 가지를 동시에 만족하는 것이 핵심 원칙.
> 규칙: 작업 시작 시 이 파일을 먼저 읽고, 완료 시 갱신할 것.

## 현재 베이스
- 최신 파일: `kids-chess/prototype/v0.1.html` (단일 파일, 오프라인 동작, 외부 의존성 0)
- 다음 작업 산출물: `v0.2.html` (버전 올려 생성)

## v0.1 구현 내용 (MVP 1차)
- **정통 체스 엔진(자체 구현)**: 합법수 생성, 체크/체크메이트/스테일메이트, 캐슬링, 앙파상, 프로모션
  - 정확성 검증: perft(start)=20/400/8902/197281, perft(Kiwipete)=48/2039/97862 모두 일치
- **배우기**: 6개 말 움직임 레슨(별 모으기) + 잡기/체크/캐슬링/체크메이트 개념 레슨 = 10개
- **퍼즐**: 외통 1수·공짜 말·체크·체크 피하기 10문제(엔진이 정답 판정), 단계별 힌트
- **대국**: 캐릭터 AI 5단계(병아리/토끼/여우/사자/드래곤) + 2인용(친구랑)
  - 어린이 보호: 약한 AI는 일부러 실수, 외통수는 항상 둠, 체크/외통 위험 경고 토스트
  - 되돌리기(라운드 단위), 단계별 힌트, 잡힌 말 표시, 마지막 수 하이라이트
- **게임화**: 스티커 9종(학습 행동 보상 중심, 도박성/랭킹 없음)
- **부모님 메뉴**: 곱셈 게이트로 진입, 학습 리포트(시간/레슨/퍼즐 정답률/승패/스티커), 추천 다음 학습, 힌트 on/off, 기록 초기화
- **안전**: 모든 기록 localStorage(기기 내) 저장, 계정/개인정보 수집 없음, 외부 링크 없음

## 작업 큐 (우선순위 순)

### 🔴 1순위 — 콘텐츠 확장
- [ ] 퍼즐 10 → 100개 (난이도 태그, 틀린 문제 자동 재출제 = 간격 반복)
- [ ] 레슨 10 → 30개 (레벨 1~5 커리큘럼 완성, 캐릭터 안내 문구)
- [ ] 대국 후 "복기" 화면 (오늘의 좋은 수 / 다음엔 조심할 수)

### 🟡 2순위 — UX/접근성
- [ ] 말 이동 애니메이션(슬라이드) + 효과음 토글(WebAudio, 무에셋)
- [ ] 보드 뒤집기(흑 선택 대국), 큰 글씨/색약 모드
- [ ] 터치 타깃·대비 점검, reduced-motion 대응
- [ ] 하루 사용 시간 제한(부모 설정) 실제 잠금 동작

### 🟢 3순위 — 출시 준비
- [ ] Flutter/React Native 래핑 검토(웹뷰 또는 포팅)
- [ ] 개인정보처리방침/아동 개인정보 보호(COPPA/개인정보보호법) 검토
- [ ] 앱스토어/플레이스토어 "어린이용 + 광고 없음" 표기, 부모 소개 페이지
