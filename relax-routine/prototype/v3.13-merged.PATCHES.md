# Relax Routine v3.13 병합 패치

- 기준 원본: `v3.10.6.html`
- 산출물: `v3.13-merged.html`
- 구조: 원본 바이트를 유지하고 외부 문서의 마지막 `</body>` 직전에 `#rr-v313-merged-css`와 `#rr-v313-merged-patch` 각 1개만 추가했다.
- 런타임: 원본 부트가 `documentElement`를 내장 템플릿으로 교체하므로, 스크립트가 CSS 원문을 먼저 캡처한 뒤 새 문서 `<head>`의 마지막 스타일로 재주입·유지한다.

## 병합 판단

Claude 후보의 런타임 CSS 재주입, 팔레트별 캘린더 색 보정, 추천 패널 자체 닫기 연동을 기반으로 삼았다. Codex 후보의 시스템 산세리프 전역화, 외부 위기 모달 포함 오버레이 범위, Tab 포커스 순환, 중간폭 패널 중앙 정렬을 결합했다. 중복 스타일/스크립트는 복사하지 않고 최종 ID 한 쌍으로 정리했으며, 8px 주차 라벨을 10px로 두던 예외는 병합 스펙의 `≥12px` 요구에 맞춰 제거했다.

## 보존 및 안전

- 브랜드 라임 `#A8CC4D`는 기존 템플릿에서 변경하지 않았다.
- 안전 도움 진입점, 자살예방상담전화 109, 정신건강위기상담 1577-0199, 119, 응급 대응 도구가 아니라는 면책 문구를 그대로 유지했다.
- 원본 React 컴포넌트와 `__bundler/template` JSON 문자열은 수정하지 않았다.
