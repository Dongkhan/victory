# 자녀 능동성 및 상호 계약 모델 설계

## 1. 설계 목표

Family Link Coach의 핵심 차별화는 부모가 일방적으로 통제하는 구조가 아니라, 자녀가 규칙의 이유를 이해하고 목표·요청·수정·리뷰에 참여하는 구조다.

제품 원칙:

1. 규칙은 부모가 정하지만, 아이는 목표와 실행 방법에 참여한다.
2. 제한은 처벌이 아니라 자기조절 훈련의 안전장치로 설명한다.
3. 위반 후에는 장기 압수보다 짧은 회복 루프를 제공한다.
4. 부모와 아이 양쪽 모두 계약의 책임을 가진다.
5. 아이의 자율권은 한 번에 주거나 빼앗는 것이 아니라 단계적으로 회복된다.
6. 앱은 몰래 감시, 메시지 열람, 위치 추적, 우회법 안내를 제공하지 않는다.

핵심 사용자 경험:

- 부모: “어떻게 제한할까?”가 아니라 “어떤 약속을 같이 만들까?”로 전환
- 아이: “빼앗긴다”가 아니라 “내가 지키면 선택권이 늘어난다”로 전환
- 가족: 말싸움이 아니라 기록된 계약과 주간 리뷰로 조정

## 2. 전체 기능 지도

자녀 능동성 기능 묶음:

1. 아이 목표 선택
2. 상호 계약서 작성
3. 오늘의 약속 확인
4. 추가시간 요청
5. 규칙 수정 제안
6. 위반 후 회복 플랜
7. 주간 리뷰
8. 자율권 회복 단계
9. 부모-아이 서명 플로우

기능 간 관계:

1. 부모 온보딩 설문 → 추천 규칙 초안 생성
2. 아이 목표 선택 → 계약서의 “이번 주 나의 목표”에 반영
3. 부모와 아이가 계약서 조정 → 양쪽 서명 후 활성화
4. 일상 사용 중 아이가 추가시간 요청 또는 규칙 수정 제안
5. 부모는 즉시 승인/거절하거나 주간 리뷰로 보류
6. 주간 리뷰에서 지킨 점, 어려운 점, 다음 주 조정안을 합의
7. 일정 기간 성공하면 자율권 회복 단계 상승

## 3. 화면 설계

### 3.1 부모 홈: 가족 디지털 약속 대시보드

목적:

- 현재 계약 상태, 오늘의 규칙, 요청 대기, 리뷰 일정을 한눈에 표시

주요 컴포넌트:

- 자녀 카드
  - 이름, 나이/학년
  - 현재 계약 상태: 초안 / 서명 대기 / 활성 / 리뷰 필요 / 일시 중지
  - 오늘 남은 사용시간
  - 이번 주 약속 지킨 날 수
  - 자율권 단계
- 요청함
  - 추가시간 요청 n건
  - 규칙 수정 제안 n건
- 다음 리뷰
  - 날짜, 예상 소요 시간, 준비 필요 항목
- 빠른 버튼
  - 계약서 보기
  - 요청 처리
  - 오늘 대화문 보기
  - 주간 리뷰 시작

부모용 문구:

- “오늘은 제한보다 약속 확인이 먼저입니다.”
- “요청을 바로 판단하기 어렵다면 주간 리뷰로 넘길 수 있습니다.”
- “거절도 설명과 다음 기회가 있으면 처벌보다 계약이 됩니다.”

### 3.2 아이 홈: 오늘의 약속

목적:

- 아이가 오늘 지켜야 할 약속, 남은 선택권, 요청 가능 범위를 직접 확인

주요 컴포넌트:

- 오늘의 한 줄 목표
- 오늘 가능한 디지털 사용
  - 총 시간
  - 게임/숏폼/학습/연락/창작 등 목적별 구분
- 먼저 할 일
  - 숙제, 준비물, 씻기, 충전 위치 등
- 요청 버튼
  - 추가시간 요청
  - 규칙이 어려워요
  - 오늘 성공 체크
- 자율권 단계 표시
  - 현재 단계와 다음 단계 조건
- 부모에게 보낼 짧은 메시지 입력

아이용 문구:

- “이 약속은 너를 감시하려는 게 아니라, 네가 스스로 조절하는 연습을 돕기 위한 거야.”
- “필요하면 이유를 써서 추가시간을 요청할 수 있어.”
- “어려운 규칙은 주간 리뷰에서 바꿔보자고 제안할 수 있어.”
- “오늘 못 지켜도 끝이 아니야. 회복 규칙을 지키면 다시 시작할 수 있어.”

### 3.3 아이 목표 선택 화면

목적:

- 아이가 스스로 이번 주 목표를 선택하게 하여 계약의 주체감을 만든다.

입력 방식:

- 카드 선택 1~2개
- 자유 입력 선택 가능
- 부모가 최종 검토하지만, 목표 문구는 아이 표현을 최대한 유지

목표 카드 예시:

- “게임을 끊을 때 덜 화내기”
- “밤에는 폰을 거실에 두기”
- “숙제 끝나고 게임하기”
- “숏폼을 보기 전에 시간을 정하기”
- “부모님이 말하기 전에 스스로 멈춰보기”
- “연락 앱은 필요할 때만 쓰기”
- “창작이나 공부에 쓰는 시간 늘리기”

아이용 선택 문구:

- “이번 주에 내가 연습하고 싶은 것을 골라보세요.”
- “완벽하게 하는 목표가 아니라, 지난주보다 조금 나아지는 목표입니다.”
- “부모님이 정해주는 목표와 내가 고른 목표를 같이 계약서에 넣습니다.”

부모용 보조 문구:

- “아이 목표는 너무 크지 않아야 합니다. ‘폰 줄이기’보다 ‘게임 종료 알림 후 10분 안에 마무리’가 좋습니다.”

### 3.4 상호 계약서 작성 화면

목적:

- 추천 규칙을 부모-아이 공동 약속 문서로 전환한다.

화면 구성:

1. 계약 제목
   - 예: “민준이의 5월 4주 디지털 약속”
2. 이번 주 공동 목표
   - 부모 목표
   - 아이 목표
3. 사용 규칙
   - 평일 총량
   - 주말 총량
   - 목적별 사용
   - 항상 허용 앱
   - 취침 전 규칙
4. 먼저 할 일
   - 숙제/식사/씻기/준비물/충전 위치
5. 추가시간 요청 규칙
6. 규칙 수정 제안 규칙
7. 위반 후 회복 규칙
8. 부모의 약속
9. 아이의 약속
10. 다음 리뷰 날짜
11. 서명

계약서 문구 템플릿:

- “우리 가족은 스마트폰을 없애기 위해서가 아니라, 필요한 만큼 잘 쓰기 위해 이 약속을 만듭니다.”
- “부모는 이유를 설명하지 않는 갑작스러운 압수를 하지 않겠습니다.”
- “아이는 정해진 시간이 어렵거나 추가시간이 필요할 때 숨기지 않고 요청하겠습니다.”
- “약속을 지키지 못한 날에도 회복 규칙을 지키면 다음 날 다시 시작합니다.”
- “이 계약은 가족을 벌주기 위한 문서가 아니라, 다음 주에 더 잘 맞게 고치기 위한 문서입니다.”

### 3.5 추가시간 요청 화면

목적:

- 아이가 몰래 사용하거나 말싸움으로 요구하지 않고, 구조화된 요청을 하게 한다.

아이 입력 항목:

- 요청 시간: 10분 / 20분 / 30분 / 직접 입력
- 이유 선택
  - 친구와 약속된 게임/대화가 남음
  - 학습/과제에 필요함
  - 창작/영상/코딩 등 만들기 활동 중임
  - 가족과 상의하고 싶은 특별한 이유가 있음
- 오늘 먼저 한 일 체크
- 대신 줄일 시간 선택
  - 내일 시간에서 차감
  - 주말 시간에서 차감
  - 토큰 사용
  - 오늘은 예외 요청
- 아이 메시지

부모 결정 옵션:

- 승인
- 일부 승인
- 오늘은 거절, 주간 리뷰에서 논의
- 내일/주말 시간으로 이동
- 토큰 사용 시 승인

아이용 요청 문구:

- “그냥 더 하고 싶어요”보다 “왜 필요한지”를 쓰면 승인 가능성이 높아집니다.
- “부모님이 거절해도 다음 리뷰에서 다시 제안할 수 있습니다.”
- “몰래 쓰면 선택권이 줄어들고, 요청하면 선택권을 연습하는 것입니다.”

부모용 판단 문구:

- “승인은 예외가 아니라 계약 안의 절차입니다.”
- “거절할 때는 ‘안 돼’만 쓰지 말고 이유와 다음 기회를 같이 남기세요.”

부모 응답 템플릿:

- 승인: “오늘은 이유가 분명하고 먼저 할 일을 끝냈으니 20분 승인할게. 끝나는 시간은 8:20이야.”
- 일부 승인: “30분은 어렵고 10분은 가능해. 내일 시간에서 10분 줄이는 조건으로 승인할게.”
- 거절: “오늘은 취침시간이 가까워서 추가시간은 어렵다. 대신 금요일 리뷰에서 주말 시간 조정을 같이 보자.”
- 보류: “지금 바로 결정하기 어렵다. 이번 주 리뷰에서 규칙을 바꿀지 같이 이야기하자.”

### 3.6 규칙 수정 제안 화면

목적:

- 아이가 “규칙이 불공정하다”는 감정을 행동화하지 않고 수정 제안으로 표현하게 한다.

아이 입력 항목:

- 바꾸고 싶은 규칙
- 어려운 이유
- 내가 제안하는 새 규칙
- 대신 지킬 수 있는 조건
- 언제부터 적용하고 싶은지
- 부모에게 전하고 싶은 말

수정 제안 카테고리:

- 시간이 너무 짧음
- 요일별 차이가 필요함
- 학습/연락/창작 앱이 제한에 걸림
- 친구 약속과 맞지 않음
- 취침 규칙이 현실과 맞지 않음
- 보상이 동기부여가 안 됨
- 부모의 규칙 적용이 일관되지 않음

처리 상태:

- 제출됨
- 부모 확인 필요
- 주간 리뷰 안건 등록
- 승인됨
- 일부 승인됨
- 거절됨
- 다음 주 재검토

아이용 문구:

- “규칙이 마음에 안 들면 깨는 대신 바꾸자고 제안할 수 있습니다.”
- “좋은 제안은 ‘더 하고 싶다’가 아니라 ‘이렇게 하면 나도 지킬 수 있다’입니다.”

부모용 문구:

- “아이의 제안을 모두 승인할 필요는 없습니다. 다만 제안을 검토하는 절차 자체가 자율성 훈련입니다.”
- “규칙 수정은 즉흥 말싸움 중이 아니라 주간 리뷰에서 다룹니다.”

### 3.7 위반 후 회복 플랜 화면

목적:

- 위반을 장기 처벌로 연결하지 않고, 다음 행동을 명확히 한다.

회복 플랜 구성:

1. 오늘 무슨 일이 있었나
   - 시간 초과
   - 몰래 사용
   - 취침 후 사용
   - 종료 분노
   - 약속 전 해야 할 일 미완료
2. 감정 체크
   - 화남, 억울함, 불안함, 심심함, 끊기 어려움, 별생각 없음
3. 회복 행동 선택
   - 부모에게 사실 말하기
   - 오늘 기기 거실 충전
   - 내일 시작 전 약속 다시 읽기
   - 10분 대체활동 하기
   - 주간 리뷰 안건으로 등록
4. 다음 날 기본시간 회복 조건
5. 부모 반응 스크립트

부모용 문구:

- “지금은 이긴 사람과 진 사람을 정하는 시간이 아닙니다. 다음에 같은 일이 생겼을 때 어떻게 회복할지 정하는 시간입니다.”
- “거짓말을 줄이려면 사실을 말했을 때 회복 경로가 있어야 합니다.”

아이용 문구:

- “약속을 못 지킨 날도 회복 행동을 하면 다시 시작할 수 있습니다.”
- “숨기는 것보다 말하고 회복하는 것이 더 높은 단계의 선택입니다.”

### 3.8 주간 리뷰 화면

목적:

- 한 주의 성공과 실패를 평가하고, 다음 주 규칙을 조정한다.

진행 시간:

- 5~10분
- 주 1회 고정
- 갈등 직후가 아니라 안정된 시간에 진행

리뷰 단계:

1. 이번 주 계약 확인
2. 아이 자기평가
3. 부모 관찰
4. 잘 된 점 1~3개
5. 어려웠던 상황 1~3개
6. 추가시간 요청/수정 제안 검토
7. 다음 주 규칙 조정
8. 자율권 단계 유지/상승/하락 결정
9. 새 계약서 서명 또는 기존 계약 연장

아이 자기평가 질문:

- “이번 주에 내가 제일 잘 지킨 약속은?”
- “제일 어려웠던 시간은?”
- “부모님이 도와주면 더 쉬워질 점은?”
- “다음 주에 내가 바꾸고 싶은 규칙은?”
- “내가 더 책임질 수 있는 부분은?”

부모 관찰 질문:

- “아이가 스스로 멈춘 순간이 있었나?”
- “부모가 갑자기 화내거나 규칙을 바꾼 순간이 있었나?”
- “규칙이 너무 엄격하거나 너무 느슨했나?”
- “아이의 요청 중 정당한 요청이 있었나?”

주간 리뷰 결론 템플릿:

- 유지: “이번 주 규칙은 대체로 맞았습니다. 다음 주도 같은 규칙으로 갑니다.”
- 완화: “스스로 멈춘 날이 4일 이상이어서 주말 창작 시간 30분을 추가합니다.”
- 강화: “취침 후 사용이 2회 있어, 다음 주는 충전 위치를 거실로 고정합니다.”
- 조정: “게임 시간은 유지하고, 학습앱은 항상 허용으로 분리합니다.”

### 3.9 자율권 회복 단계 화면

목적:

- 아이가 ‘통제에서 자유’가 아니라 ‘책임을 보이면 선택권이 늘어나는 구조’를 보게 한다.

단계 모델:

#### 0단계: 안전 재정비

적용 상황:

- 취침 후 몰래 사용 반복
- 종료 분노가 심함
- 부모 기기 접근 또는 비밀번호 문제
- 생활 기능 저하가 뚜렷함

권한:

- 부모 주도 규칙
- 짧은 사용 단위
- 취침 전 기기 분리
- 추가시간 요청 제한적 허용

회복 조건:

- 3일 연속 거실 충전
- 종료 알림 후 큰 갈등 없이 마무리 2회
- 사실 말하기 1회 이상

#### 1단계: 함께 정한 기본 약속

적용 상황:

- 기본 규칙이 필요하지만 아이가 참여 가능

권한:

- 아이 목표 선택
- 추가시간 요청 가능
- 주간 리뷰 참여
- 일부 앱 목적 구분 가능

상승 조건:

- 한 주 4일 이상 핵심 약속 준수
- 추가시간 요청을 절차대로 사용
- 취침 규칙 위반 1회 이하

#### 2단계: 선택권 확장

권한:

- 주말 시간 일부 선택
- 창작/학습 앱 별도 분리 제안 가능
- 토큰 사용 가능
- 규칙 수정 제안 가능

상승 조건:

- 2주 연속 주간 목표 달성
- 부모 알림 전 스스로 종료 3회 이상
- 위반 시 회복 플랜 완료

#### 3단계: 자기관리 실험

권한:

- 일부 시간대를 아이가 직접 배분
- 부모 승인 없이 작은 범위의 시간 이동 가능
- 주간 리뷰에서 다음 주 규칙 공동 설계

유지 조건:

- 취침·학습·가족 약속을 해치지 않음
- 사용 후 후회/갈등 기록이 증가하지 않음

#### 4단계: 신뢰 기반 관리

권한:

- 부모는 모니터링보다 주간 리뷰 중심
- 시간 총량보다 생활 균형 목표 중심
- 아이가 자기조절 계획을 먼저 제안

하락 조건:

- 반복적 은폐
- 취침 후 사용 재발
- 가족 약속이나 학교 기능의 현저한 악화

단계 안내 문구:

- “단계는 벌점표가 아니라 연습 수준입니다.”
- “단계가 내려가도 실패가 아니라 다시 안전하게 시작하는 것입니다.”
- “선택권은 요구해서 얻는 것이 아니라 책임을 보여서 넓어집니다.”

## 5. 부모-아이 서명 플로우

### 5.1 기본 플로우

1. 부모가 온보딩 설문 완료
2. 앱이 규칙 초안 생성
3. 부모가 초안을 검토하고 아이에게 공유
4. 아이가 목표 선택 및 이해 확인
5. 부모와 아이가 계약서 화면을 함께 확인
6. 앱이 핵심 조항을 한 줄씩 보여줌
7. 아이가 “이해했어요 / 어려운 점이 있어요” 선택
8. 어려운 점이 있으면 규칙 수정 제안 또는 부모 메모로 저장
9. 부모 서명
10. 아이 서명
11. 계약 활성화
12. PDF/공유용 문서 생성
13. 다음 리뷰 일정 자동 등록

### 5.2 서명 전 이해 확인 문항

아이에게 보여줄 질문:

- “이번 주 내가 연습할 목표를 알고 있나요?”
- “추가시간이 필요할 때 어떻게 요청하는지 알고 있나요?”
- “약속을 못 지킨 날 다시 시작하는 방법을 알고 있나요?”
- “이 규칙 중 너무 어렵다고 느끼는 부분이 있나요?”

선택지:

- 알고 있어요
- 조금 헷갈려요
- 바꾸고 싶은 부분이 있어요

### 5.3 부모 서명 전 확인 문항

부모에게 보여줄 질문:

- “갑작스러운 장기 압수보다 회복 규칙을 먼저 적용하겠습니다.”
- “아이의 추가시간 요청을 말싸움이 아니라 계약 절차로 다루겠습니다.”
- “규칙 변경은 가능하면 주간 리뷰에서 하겠습니다.”
- “아이의 학습·연락·창작 목적 사용을 단순 오락과 구분하겠습니다.”

### 5.4 서명 완료 문구

공동 완료 문구:

- “이번 주 디지털 약속이 시작되었습니다.”
- “완벽하게 지키는 것보다, 어려울 때 말하고 다시 시작하는 것이 중요합니다.”
- “다음 리뷰에서 가족에게 맞게 고칠 수 있습니다.”

## 6. 연령대별 설계 차이

### 6.1 초등 저학년: 7~9세

특징:

- 시간 개념과 자기조절이 아직 약함
- 부모의 시각적 안내와 즉각적 피드백이 중요
- 계약은 짧고 구체적이어야 함

화면 설계:

- 글보다 그림/아이콘 중심
- 선택지는 2~3개로 제한
- “오늘 먼저 할 일” 체크리스트 중심
- 추가시간 요청은 10분 단위 고정
- 규칙 수정 제안은 자유 입력보다 감정/어려움 카드 선택

계약 문구:

- “게임은 숙제와 씻기를 끝낸 뒤에 합니다.”
- “알림이 울리면 10분 안에 마무리합니다.”
- “밤에는 폰이 거실에서 쉽니다.”

부모 지침:

- 긴 설명보다 같은 규칙을 반복
- 실패 시 즉시 장기 처벌 금지
- 성공 체크와 회복 행동을 짧게

### 6.2 초등 고학년: 10~12세

특징:

- 공정성에 민감
- 친구와의 비교가 증가
- 규칙의 이유를 설명해야 수용성이 올라감

화면 설계:

- 목표 선택과 추가시간 요청 활성화
- 사용 목적 구분 도입: 학습/연락/게임/영상/창작
- 주간 리뷰에서 아이 의견 1개 이상 의무 반영
- 자율권 단계 시각화

계약 문구:

- “친구와의 약속이 있는 날은 미리 요청합니다.”
- “학습 앱과 게임 앱은 다르게 봅니다.”
- “규칙이 안 맞으면 깨는 대신 주간 리뷰에서 바꾸자고 제안합니다.”

부모 지침:

- “다른 집은 상관없어”보다 우리 가족 기준 설명
- 승인/거절 이유를 짧게 기록
- 아이가 제안한 현실적 조정안은 일부라도 반영 고려

### 6.3 중학생: 13~15세

특징:

- 자율성 욕구가 커지고 감시 반감이 강함
- 친구관계, 학업, 수면, 게임/숏폼이 복합적으로 얽힘
- 일방 통제는 우회 동기를 높일 수 있음

화면 설계:

- 계약서에 “부모의 약속” 비중 확대
- 아이가 자기관리 실험을 제안할 수 있게 함
- 시간 총량보다 취침, 학업, 가족 약속 등 생활 기능 지표 포함
- 규칙 수정 제안과 주간 리뷰를 핵심 기능으로 배치

계약 문구:

- “부모는 몰래 확인하지 않고, 필요한 점검은 계약서에 적힌 방식으로 합니다.”
- “나는 취침, 학교, 가족 약속을 해치지 않는 범위에서 선택권을 넓혀갑니다.”
- “숨기거나 우회하기보다, 맞지 않는 규칙을 수정 제안합니다.”

부모 지침:

- 감시 언어 최소화
- 메시지 내용 확인, 위치 추적, 몰래 점검을 기본값으로 두지 않음
- 우회 시도는 처벌만이 아니라 규칙 수용성 저하 신호로 검토

### 6.4 고등학생: 16~18세

특징:

- 성인 전환기의 자기관리 연습이 중요
- 진로, 학업, 수면, 대인관계, 정서 문제가 복합적
- 부모 통제보다 자기계약과 리뷰 중심이 적합

화면 설계:

- 자기관리 플랜 중심
- 부모 승인보다 공동 리뷰와 안전 기준 중심
- 디지털 사용을 소비형/창작형/학습형/관계형으로 구분
- 목표는 가치기반 문구 사용

계약 문구:

- “나는 내가 원하는 삶과 수면, 학업, 관계를 해치지 않는 방식으로 디지털 사용을 조절합니다.”
- “부모는 독립을 준비하는 과정으로 보고, 필요한 안전 기준만 함께 점검합니다.”
- “위험 신호가 있을 때는 통제보다 도움 요청을 우선합니다.”

부모 지침:

- 미성년 안전 기준은 유지하되, 세부 시간 통제는 점진적으로 줄임
- 수면 붕괴, 등교 문제, 우울/자해 위험, 폭력/착취 위험은 별도 개입 필요
- 앱은 치료나 위기 대응을 대체하지 않음

## 7. 안전·임상·정책 문구

앱 내 고정 안내:

- “이 앱은 부모교육과 가족 디지털 사용 약속을 돕는 도구입니다. 의학적 진단이나 치료를 대신하지 않습니다.”
- “자해, 자살 생각, 폭력 위험, 심한 우울, 조증, 정신증, 학대나 착취 위험이 있으면 즉시 보호자, 의료진, 응급기관 등 실제 도움을 요청해야 합니다.”
- “자녀의 메시지 내용, 사적 대화, 위치를 몰래 확인하는 기능은 제공하지 않습니다.”
- “기술적 제한보다 가족 간 예측 가능한 규칙과 회복 절차를 우선합니다.”

부모 과잉통제 방지 문구:

- “모든 앱을 막는 것이 목표가 아닙니다. 수면, 학업, 관계, 감정조절을 해치지 않는 사용을 만드는 것이 목표입니다.”
- “규칙이 너무 강하면 숨김과 우회가 늘 수 있습니다. 아이가 지킬 수 있는 최소 규칙부터 시작하세요.”

아이 보호 문구:

- “부모에게 말하기 어렵거나 집에서 안전하지 않다고 느끼면, 신뢰할 수 있는 어른이나 전문가에게 도움을 요청하세요.”

## 10. 성공 지표

제품 지표:

- 첫 계약서 생성 완료율
- 부모-아이 양쪽 서명 완료율
- 아이 목표 선택 완료율
- 추가시간 요청 중 말싸움 없이 처리된 비율
- 주간 리뷰 완료율
- 규칙 수정 제안의 검토 완료율
- 자율권 단계 상승 또는 안정 유지 비율

임상·가족 기능 지표:

- 취침 후 사용 감소
- 종료 시 갈등 강도 감소
- 몰래 사용 보고 감소 또는 사실 말하기 증가
- 부모의 장기 압수 빈도 감소
- 아이의 자기중단 성공 경험 증가

주의:

- 사용시간 감소만을 단독 성공지표로 두지 않는다.
- 아이가 숨기지 않고 요청·리뷰에 참여하는 것도 핵심 성과로 본다.
