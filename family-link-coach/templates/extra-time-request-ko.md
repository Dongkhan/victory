# 추가시간 요청서

용도: 자녀가 게임·영상·SNS·채팅 등의 추가시간을 보호자에게 설명하고 요청하기 위한 짧은 양식
원칙: 추가시간은 자동 보상이 아니며, 수면·안전·등교 준비를 해치지 않아야 합니다.

---

## 1. 요청 내용

오늘 날짜: ______년 ____월 ____일

요청하는 활동:

- [ ] 게임
- [ ] 영상
- [ ] 친구와 연락
- [ ] SNS
- [ ] 숙제/학습 목적
- [ ] 기타: __________________________

요청 시간:

- 지금 정해진 종료 시간: ______시 ______분
- 더 필요한 시간: ______분
- 새 종료 시간: ______시 ______분

---

## 2. 요청 이유

가장 가까운 이유를 고릅니다.

- [ ] 하던 판/영상/대화를 마무리해야 한다.
- [ ] 친구와 미리 약속한 시간이 남아 있다.
- [ ] 숙제나 과제에 실제로 필요하다.
- [ ] 오늘 약속을 대부분 지켰고, 짧게 조정하고 싶다.
- [ ] 기분이 많이 흔들려서 잠깐 정리 시간이 필요하다.
- [ ] 기타: __________________________________________

내 말로 설명하기:

____________________________________________________________

____________________________________________________________

---

## 3. 내가 먼저 확인할 것

- [ ] 숙제/준비물/씻기/식사는 끝냈다.
- [ ] 내일 등교나 일정에 큰 지장이 없다.
- [ ] 추가시간이 끝나면 바로 멈출 방법을 정했다.
- [ ] 알람 또는 타이머를 켤 수 있다.
- [ ] 부모가 거절해도 다시 이야기할 수 있다.

---

## 4. 종료 약속

추가시간이 허용되면 나는 다음 방식으로 종료하겠습니다.

- [ ] 타이머가 울리면 멈춘다.
- [ ] 5분 전 알림을 받으면 마무리한다.
- [ ] 종료 후 기기를 정한 장소에 둔다.
- [ ] 종료 후 짧게 기분을 기록한다.
- [ ] 종료가 어려우면 회복 플랜을 작성한다.

내 종료 문장:

“______________________________________________”

---

## 5. 보호자 결정

- [ ] 승인: ______분 추가, 새 종료 시간 ______시 ______분
- [ ] 조건부 승인: 조건 ______________________________________
- [ ] 보류: 먼저 _____________________________________________
- [ ] 거절: 이유 _____________________________________________

부모가 설명할 문장:

오늘 결정은 벌이나 보상이 아니라 수면, 준비, 약속을 함께 맞추기 위한 결정이야. 다음에 더 쉽게 승인받으려면 어떤 점을 먼저 준비하면 좋을지 같이 정하자.

---

## 6. 사용 후 짧은 확인

- [ ] 정한 시간에 종료했다.
- [ ] 종료가 어려웠지만 도움을 받아 멈췄다.
- [ ] 종료하지 못해 회복 플랜이 필요하다.
