# 우리집 디지털 약속 최종 제품 기획 문서

작성일: 2026-05-24
내부 코드명: Family Link Coach
외부 권장 서비스명: 우리집 디지털 약속
문서 목적: 의사결정자, 개발자, 임상가가 바로 읽고 실행할 수 있는 최종 제품 계획
반영 범위: T9 통합 제품 계획안과 T10 안전정책·임상·제품 리스크 리뷰, 기술 구조, 부모교육, 자녀 능동성, 보상, 대체활동, MVP 실행계획

---

## 0. 최종 결론

우리집 디지털 약속은 Family Link를 대체하거나 더 강하게 잠그는 앱이 아니다. 이미 존재하는 Family Link, Apple Screen Time, 기타 parental control 도구 위에 얹히는 가족 디지털 습관 코칭 레이어다.

핵심 제품 정의:

> 부모가 Family Link를 켜기 전후에, 자녀와 함께 디지털 규칙을 정하고 갈등을 줄이며 자율성을 회복하도록 돕는 가족 디지털 계약·부모교육·주간 리뷰 도구.

최종 전략:

1. P0는 웹/PWA로 출시한다.
2. P0는 강제 차단, 자동 감시, 위치추적, 메시지 열람, 우회 탐지 기능을 포함하지 않는다.
3. 핵심 가치는 차단 강도가 아니라 갈등 비용 감소다.
4. 자녀는 통제 대상이 아니라 규칙 운영의 공동 참여자다.
5. 부모에게 “더 세게 막는 법”이 아니라 “덜 싸우고 지속 가능한 규칙을 운영하는 법”을 제공한다.
6. 임상 표현은 진단이 아니라 생활 패턴 정리로 제한한다.
7. 아동 데이터는 부모 소유물이 아니라 자녀의 민감한 생활기록으로 취급한다.
8. 4주 MVP의 목적은 기술 통제 검증이 아니라 계약서 생성, 설정 가이드, 부모교육, 대체활동, 주간 리뷰가 실제 갈등을 줄이는지 검증하는 것이다.

## 1. 제품 포지셔닝

### 1.1 시장 내 위치

기존 parental control 시장은 다음 기능을 중심으로 발전했다.

- 화면시간 제한
- 앱·웹 차단
- 위치 확인
- 구매 승인
- 위험 콘텐츠 탐지
- 사용량 리포트

이 제품들이 약한 지점은 다음이다.

- 아이가 통제당한다고 느끼는 문제
- 종료 시점의 분노와 말싸움
- 몰래 사용 후 처벌-반항 루프
- 부모가 기준을 자주 바꾸는 문제
- 규칙의 이유가 설명되지 않는 문제
- 자율성 회복 경로 부재
- ADHD, 불안, 우울, 수면 지연, 게임몰입, 숏폼 과사용 등 생활 패턴별 조정 부재
- 주간 단위 가족 리뷰 부재

우리집 디지털 약속의 시장 기회는 “더 강한 차단”이 아니라 “가족 내 운영 프로토콜”이다.

### 1.2 한 줄 포지셔닝

Family Link의 기술적 제한을 가족 디지털 계약, 자녀 참여, 부모교육, 대체활동, 자기조절 연습 기록, 주간 리뷰로 바꾸는 부모-자녀 디지털 습관 코치.

### 1.3 외부 서비스명

권장명: 우리집 디지털 약속

이유:

- 감시·차단보다 약속·합의·가족 운영의 의미가 강하다.
- 한국 부모에게 즉시 이해된다.
- 자녀에게 위협적이지 않다.
- Family Link라는 Google 상표 의존을 피한다.
- 계약서, 규칙, 주간 리뷰라는 핵심 기능과 잘 맞는다.

내부 코드명 Family Link Coach는 개발 문서에서만 사용한다. 외부 마케팅, 앱 이름, 결제 상품명에는 Family Link를 직접 포함하지 않는다.

## 2. 대상 고객

### 2.1 1차 고객

- 초등 고학년~중학생 자녀를 둔 부모
- Family Link나 Screen Time을 이미 쓰거나 쓰려는 부모
- 스마트폰, 게임, 숏폼 때문에 반복적으로 말싸움을 하는 가정
- 종료 전환, 수면 지연, 숙제 지연, 몰래 사용, 친구 핑계, 게임 이벤트 문제로 갈등이 반복되는 가정
- 전문 치료 앱보다는 실무적인 부모교육·계약서·설정 가이드를 원하는 가정

### 2.2 2차 고객

- 소아청소년 정신건강의학과
- 상담센터
- 부모교육 기관
- 학교·지역센터 부모교육 프로그램
- 진료실에서 부모에게 출력물과 계약서가 필요한 전문가

### 2.3 초기 유료화 우선순위

1순위: 진료실·상담센터 보조도구
2순위: 부모교육 PDF/워크북 패키지
3순위: B2C 웹앱 구독
4순위: 부모/자녀 앱 연동형 SaaS

이유: 앱스토어 심사와 OS 권한 이슈 없이 바로 판매 가능한 형태는 전문가용 워크북·계약서·설정 가이드 번들이다.

## 3. 해결할 문제

### 3.1 부모의 문제

1. Family Link나 Screen Time 메뉴는 알지만 자기 아이에게 어느 정도 제한이 적절한지 모른다.
2. 평일, 주말, 숙제, 학원, 친구관계, 게임 이벤트를 반영하지 못한다.
3. 종료 지시가 반복되며 부모가 감시자 역할로 고착된다.
4. 아이가 약속과 다르게 사용하면 장기 압수, 즉시 차단, 비난으로 대응하기 쉽다.
5. 수면 지연, 전환 어려움, 불안한 연락 의존, 무기력, 게임 몰입, 숏폼 과사용을 구분하지 못한다.
6. 규칙을 만들었지만 리뷰하지 않아 실패한 규칙이 계속 유지된다.

### 3.2 자녀의 문제

1. 제한의 이유를 이해하지 못하고 일방적 통제로 경험한다.
2. 규칙 제정 과정에 참여하지 못한다.
3. 추가시간이 필요한 합리적 상황과 단순 회피가 구분되지 않는다.
4. 위반 후 신뢰 회복 경로가 없다.
5. 디지털 사용을 줄였을 때 대체할 활동이 준비되어 있지 않다.
6. 잘한 행동이 당연한 것으로 취급되고 자기조절 성공 경험이 축적되지 않는다.

### 3.3 제품이 제공할 변화

부모에게:

“오늘부터 아이와 덜 싸우면서 Family Link 설정을 운영할 수 있게 해준다.”

자녀에게:

“나도 규칙을 이해하고, 요청하고, 회복하고, 자율권을 되찾을 수 있다.”

## 4. 제품 원칙

1. 제한보다 합의
2. 감시보다 설명
3. 처벌보다 회복
4. 부모 단독 결정보다 자녀 참여
5. 하루 단속보다 주간 리뷰
6. 화면시간 숫자보다 사용 목적·상황·기분
7. 더 강한 차단보다 우회 욕구 감소
8. 진단보다 생활 패턴 설명
9. 보상점수보다 자기조절 연습 기록
10. OS 권한 의존보다 수동 설정 가이드와 가족 운영 UX 우선
11. 자녀 데이터의 부모 자동 공개보다 투명한 공유 범위 설정
12. 앱 규칙보다 위기 상황의 안전 확보 우선

## 5. P0에서 하지 않을 것

P0 제외 기능:

- 실제 앱 차단
- 자동 사용량 수집
- 메시지 내용 열람
- 키 입력 기록
- 화면 녹화·캡처
- 몰래 위치추적
- 브라우저 전체 URL 상시 기록
- 소셜 위험 탐지
- 자녀 모르게 백그라운드 사용기록 수집
- 감정·기분 원자료의 부모 자동 공개
- 광고 타겟팅 목적의 아동 데이터 사용
- Accessibility Service 기반 앱 차단
- DevicePolicyManager 기반 삭제 방지 또는 강제 제어
- MDM 기반 일반 가정용 관리
- FamilyControls/Screen Time entitlement 기반 차단
- 우회법 안내
- exploit 절차 제공
- 진단·치료 대체 표현
- 강제 잠금 중심 가치 제안
- 결제 시스템 내장

P0는 부모교육, 가족 계약, 수동 설정 보조, 대체활동, 자기조절 기록, 주간 리뷰에 집중한다.

## 6. 핵심 기능 구조

### 6.1 부모 온보딩

입력 항목:

- 자녀 연령대와 학년
- 주요 생활 상황: 밤 사용, 종료 갈등, 숙제 지연, 짧은 영상 과사용, 약속과 다른 사용, 연락 의존
- 평일·주말 생활패턴
- 부모의 우선 목표: 수면, 학습, 갈등 감소, 게임 조절, 숏폼 감소
- 허용해야 하는 앱: 전화, 문자, 카카오톡, 학습앱 등
- 현재 사용하는 보호 도구: Family Link, Screen Time, 기타

출력:

- 이번 주 조정이 필요한 생활 패턴
- 추천 규칙 초안
- 부모교육 카드
- 가족 디지털 계약서 초안

### 6.2 생활 패턴 정리

기존 “아이 유형 분석” 표현은 사용하지 않는다.

권장 표현:

- 종료 전환이 어려움
- 취침 전 사용이 많음
- 게임 마무리가 어려움
- 짧은 영상 자동재생에 오래 머묾
- 숙제 전 시작 지연이 반복됨
- 연락 확인이 불안과 연결됨
- 약속과 다르게 사용하는 상황이 반복됨
- 무기력하거나 대체활동 시작이 어려움

금지 표현:

- ADHD형
- 우울형
- 중독형
- 중등도 위험
- 정상/비정상
- 위험 진단

허용 표현:

- 부모교육 참고용 생활 패턴
- 이번 주 조정 주제
- 전문가 평가를 대체하지 않는 참고 정보

### 6.3 가족 디지털 계약서

필수 구성:

- 가족 공동 목표
- 평일·주말 사용 규칙
- 취침 전 충전 장소
- 항상 허용 연락 앱
- 추가시간 요청 조건
- 약속과 다르게 사용했을 때 회복 플랜
- 대체활동 선택
- 자기조절 연습 기록 방식
- 주간 리뷰 날짜
- 부모 확인
- 자녀 이해 확인

계약서 원칙:

- 한 번 정하면 끝나는 문서가 아니라 매주 수정 가능한 운영 문서다.
- 아이가 읽을 수 있는 문장으로 작성한다.
- “처벌”보다 “회복”을 중심에 둔다.
- 규칙 이유와 데이터 공유 범위를 명확히 표시한다.

### 6.4 자녀 참여 기능

| 기능 | 자녀 역할 | 부모 역할 | 제품 효과 |
|---|---|---|---|
| 목표 선택 | 수면, 숙제, 게임조절, 친구관계 중 중요한 목표 선택 | 부모 목표와 비교 | 규칙 의미 부여 |
| 계약서 확인 | 규칙 이유를 읽고 이해 확인 | 이유 설명 후 확인 | 일방 통제감 감소 |
| 추가시간 요청 | 이유, 시간, 대체 조건 제안 | 승인·거절·조건부 승인 | 몰래 사용 감소 |
| 규칙 수정 제안 | 실패한 규칙 수정 요청 | 주간 리뷰에서 조정 | 규칙 현실성 향상 |
| 회복 플랜 | 회복 행동 선택 | 처벌보다 회복 경로 제시 | 반항 루프 완화 |
| 주간 리뷰 | 잘된 점, 어려웠던 점, 다음 주 목표 제안 | 부모 반응과 규칙 조정 | 장기 지속성 향상 |
| 자율권 회복 | 신뢰 회복 조건 확인 | 단계적 권한 확대 | 통제에서 자율로 전환 |

### 6.5 자율권 회복 단계

0단계: 안전 재정비

- 위험한 야간 사용, 반복적 약속 위반, 심한 갈등 후 안정화 단계
- 목표: 비난보다 안전한 기본 구조 회복

1단계: 함께 정한 기본 약속

- 부모가 큰 틀을 제시하되 아이가 일부 선택권을 가진다.
- 목표: 규칙을 설명 가능한 형태로 정착

2단계: 선택권 확장

- 사용시간 내 앱 선택, 대체활동 선택, 추가시간 요청권 확대
- 목표: 자기조절 실험

3단계: 자기관리 실험

- 일정 조건에서 자녀가 먼저 계획하고 부모가 확인
- 목표: 부모 감시 빈도 감소

4단계: 신뢰 기반 관리

- 주간 리뷰 중심, 상시 감시 최소화
- 목표: 자율적 디지털 습관

## 7. Family Link 설정 가이드 원칙

### 7.1 P0 가이드 범위

제공할 것:

- 공식 앱에서 부모가 직접 확인해야 할 항목 체크리스트
- 일일 한도, 앱별 제한, 취침시간, 항상 허용 앱, 구매 승인 원칙
- 설정 전 가족 계약서 작성 권장
- 설정 후 주간 리뷰 권장
- 공식 도움말 링크

피할 것:

- 플랫폼 조작처럼 보이는 과도하게 상세한 단계
- 우회 가능 지점의 구체 명칭 열거
- 청소년이 검색 힌트로 사용할 수 있는 키워드
- “우회 탐지”, “해킹 방지”, “차단 해제 방지” 같은 표현

### 7.2 권장 용어 변경

| 기존 표현 | 권장 표현 |
|---|---|
| 우회가 의심될 때 | 리포트와 실제 사용이 맞지 않아 보일 때 |
| 우회 탐지 | 관리 범위 확인 |

## 9. 대체활동 기반 개입

### 9.1 목적

대체활동은 화면시간을 비우는 도구가 아니다. 아이가 디지털 사용 대신 선택할 수 있는 실제 행동 레퍼토리를 늘리는 도구다.

### 9.2 소아 모드

주요 카테고리:

- 신체활동: 점프, 산책, 공놀이
- 감각·진정 활동: 물 마시기, 숨쉬기, 촉각 놀이
- 부모와 10분 놀이: 카드게임, 블록, 역할놀이
- 생활 미션: 책가방 정리, 샤워, 잠자리 준비
- 창작: 그림, 만들기, 짧은 이야기 만들기

설계 원칙:

- 5~15분 단위
- 부모 참여 가능성 반영
- 완료보다 시작을 강화
- “폰 못 해서 하는 벌”로 보이지 않게 문구 설계

### 9.3 청소년 모드

주요 카테고리:

- 가치기반 활동: 운동, 관계, 학습, 창작, 진로
- 회복 루틴: 샤워, 스트레칭, 산책, 음악, 수면 준비
- 진로 프로젝트: 포트폴리오, 글쓰기, 영상제작, 코딩, 디자인
- 사회적 활동: 친구와 오프라인 약속, 가족 대화
- 자기관리: 공부 시작 10분, 방 정리, 다음날 준비

설계 원칙:

- 통제보다 선택권
- 유치한 보상 문구 회피
- 게임·숏폼의 기능을 대체하는 활동 추천
- 기분, 갈망, 통제감 변화는 원자료 부모 자동 공개 없이 요약 중심

### 9.4 추천 로직 v1

입력 변수:

- 나이
- 현재 시간대
- 남은 에너지
- 부모 참여 가능성
- 실내외 가능성
- 생활 패턴
- 직전 갈등 여부
- 수면까지 남은 시간
- 아이 선호 활동

출력:

- 활동 카드 3개
- 예상 시간
- 난이도
- 부모 도움 필요 여부
- 자기조절 연습 기록 기준
- 활동 전후 체크 질문

## 10. 자기조절 연습 기록과 토큰

### 10.1 정의

토큰은 “폰을 안 했으니 주는 돈”이 아니다. 토큰은 자기조절 행동의 기록이다.

### 10.2 기록 대상

- 사용 전 목적 체크
- 종료 예고를 지키기
- 스스로 종료하기
- 취침 전 충전 장소에 두기
- 대체활동 시작 또는 일부 완료
- 약속과 다르게 사용한 뒤 회복 미션 수행
- 주간 리뷰 참여
- 규칙 수정 제안 시 근거 말하기

### 10.3 사용처

권장 사용처:

- 주말 소량 추가시간
- 가족 활동 선택권
- 취미·창작 활동 선택권
- 게임·영상 대신 할 활동 고르기
- 규칙 수정 제안권
- 부모와 1:1 시간 선택

금지 사용처:

- 수면
- 식사
- 기본 애정과 돌봄
- 안전과 긴급 연락
- 치료, 상담, 약물
- 현금성 보상
- 가챠·현질·과도한 물질보상

### 10.4 패턴별 조정

| 생활 패턴 | 강화할 행동 | 피해야 할 설계 |
|---|---|---|
| 종료 전환 어려움 | 시작 전 계획, 종료 전환, 짧은 활동 완료 | 긴 지연보상, 과도한 차감 |
| 연락 의존 | 확인 시간 정하기, 안전 연락과 불안 확인 분리 | 연락 제한을 처벌로 사용 |
| 무기력·시작 어려움 | 작은 활동 시작, 부분 완료 인정 | 실패 시 전량 몰수 |
| 게임 마무리 어려움 | 게임 이벤트 사전 계획, 종료 후 회복 루틴 | 게임 추가시간만 보상으로 사용 |
| 짧은 영상 과사용 | 자동재생 중단, 짧은 신체활동, 수면 루틴 | 무제한 영상 보상 |

## 11. 안전·임상·개인정보 정책

### 11.1 임상 표현 원칙

이 제품은 진단·치료 도구가 아니다. ADHD, 우울, 불안, 게임 사용 문제를 자동 진단하거나 치료한다고 표현하지 않는다.

허용 표현:

- 생활 패턴을 정리한다.
- 가족 규칙을 함께 세운다.
- 부모교육 참고자료를 제공한다.
- 전문가 상담 전 기록을 정리하는 데 도움을 준다.
- 진단·치료를 대체하지 않는다.

금지 표현:

- ADHD를 개선한다.
- 우울/불안을 치료한다.
- 게임중독을 해결한다.
- 전문가 수준 분석.
- 임상적으로 검증된 치료 앱.
- 자녀의 위험을 자동 진단.

### 11.2 도움이 필요한 상황 안내

필수 문구:

“자녀가 죽고 싶다는 말, 자해 행동, 심한 절망감, 폭력 위협, 학대 피해, 현실과 맞지 않는 말·행동, 며칠 이상 지속되는 수면 붕괴를 보이면 앱 규칙으로 해결하려 하지 말고 즉시 보호자·전문가·응급기관에 도움을 요청하세요.”

주의:

- 무기력·우울 관련 생활 패턴 정리는 자살위험 선별이 아니다.
- 자살위험, 자해, 학대, 폭력, 현실검증 저하, 심한 기능저하는 제품 내 규칙 조정 대상이 아니라 전문가·응급 도움 안내 대상이다.

### 11.3 아동 개인정보 원칙

필수 원칙:

1. 수집 최소화: 이름은 별명 가능, 생년월일 대신 학년/연령대 사용.
2. 자유기술 최소화: 민감정보가 무제한 입력되지 않게 선택지 중심으로 설계.
3. 민감정보 경고: 진단명, 약물, 상담기록, 학교폭력, 자해, 학대 등은 일반 메모에 입력하지 않도록 안내.
4. 자녀 가시성: 자녀가 어떤 데이터가 부모에게 보이는지 확인 가능해야 한다.
5. 부모 열람 제한: 감정·갈망 원자료는 기본적으로 자녀 자기관리용으로 두고, 부모에게는 주간 요약과 자녀가 공유 동의한 항목만 표시한다.
6. 삭제권: 가족 탈퇴, 자녀 계정 연결 해제, 데이터 내보내기/삭제를 초기 설계에 포함한다.
7. 보존기간: 일일 체크인 원자료는 30~90일 후 요약값만 남기거나 삭제한다.
8. 제3자 제공 금지: 광고 목적, 타겟팅, 데이터 브로커, 외부 AI 학습 사용 금지.
9. SDK 제한: 아동 사용 화면에는 광고 SDK 금지, 분석은 비식별·집계 이벤트만 허용.
10. 열람 감사로그: 부모 또는 전문가가 민감기록을 열람하면 audit log를 남긴다.

### 11.4 부모 과잉통제 방지 장치

기능 요구사항:

1. 부모 행동 체크인
   - 이번 주에 아이 이야기를 끊지 않고 들은 적이 있나요?
   - 규칙을 갑자기 바꾼 적이 있나요?
   - 화가 난 상태에서 즉시 처벌을 정했나요?

2. 부모 과잉통제 경고 카드
   - 7일 이상 전량 차단
   - 기본 연락 제한
   - 수면·식사 거래
   - 형제 비교
   - 공개 망신
   - 자녀 몰래 감시

3. 자녀 권리 안내
   - 어떤 데이터가 기록되는지 알 권리
   - 규칙 이유를 들을 권리
   - 주간 리뷰에서 수정 제안할 권리
   - 위반 후에도 회복 경로를 가질 권리
   - 안전 연락과 기본 돌봄은 제한되지 않을 권리

4. 승인/거절 UX 기본값
   - 추가시간 요청 거절 시 “왜 안 되는지 설명 + 다음 가능한 시간 + 대체 활동” 제공
   - 즉시 차단, 전량 몰수, 무기한 압수 버튼 금지

5. 주간 리뷰 안전 규칙
   - 리뷰 시간 10~15분 제한
   - 첫 질문은 부모 평가가 아니라 자녀 경험
   - 한 번에 규칙 하나만 조정
   - 과거 위반 재추궁 금지

## 16. 주요 리스크와 대응

### 16.1 상표·브랜드 리스크

위험:

- Family Link 명칭을 외부 서비스명에 쓰면 Google 제품으로 오인될 수 있다.

대응:

- 외부명은 우리집 디지털 약속 사용
- Family Link는 “공식 parental control 설정을 가족 규칙에 맞게 운영하도록 돕는 참고 가이드”로만 표현
- 공식 제휴·대체 앱처럼 표현하지 않음

### 16.2 정책·스토어 심사 리스크

위험:

- 앱 차단, Accessibility Service, DevicePolicyManager, MDM, iOS Screen Time entitlement, 아동 개인정보 기능은 심사 리스크가 높다.

대응:

- P0는 웹/PWA와 수동 설정 가이드 중심
- 강제 차단 기능은 후순위 별도 트랙
- 공식 API와 명시적 동의 기반으로만 확장
- 앱 심사용 민감 기능 제외 목록 유지

### 16.3 임상·안전 리스크

위험:

- ADHD, 우울, 불안, 게임몰입을 진단처럼 표현할 수 있다.
- 자해, 학대, 심한 우울, 학교폭력, 수면 붕괴를 단순 규칙 문제로 축소할 수 있다.

대응:

- 진단이 아니라 생활 패턴으로 표현
- 도움이 필요한 상황 안내 필수 포함
- 치료 대체 문구 금지
- 전문가 상담 전 기록 정리 도구로 포지셔닝

### 16.4 가족갈등 악화 리스크

위험:

- 부모가 앱을 통제 강화 도구로만 사용할 수 있다.
- 자기조절 기록이 협박·거래·형제 비교 수단이 될 수 있다.

대응:

- 수면·식사·안전·기본 애정·치료는 거래 금지
- 전량 몰수·무기한 압수 금지
- 회복 플랜 우선
- 부모 과잉통제 경고 카드
- 자녀 권리 안내
- 주간 리뷰 안전 규칙

### 16.5 제품 범위 과확장 리스크

위험:

- 앱 차단, AI 코칭, 부모교육, 보상, 대체활동, 상담자 리포트까지 한 번에 만들면 MVP가 무거워진다.

대응:

- P0는 계약서·설정 체크리스트·부모교육·주간 리뷰·대체활동 카드로 제한
- 자동 사용량 수집과 강제 차단은 P2 이후
- 실제 검증 지표를 먼저 확보

## 19. 의사결정 항목

즉시 결정할 것:

1. 외부 서비스명은 우리집 디지털 약속으로 확정한다.
2. P0는 웹/PWA로 제한한다.
3. 초기 고객은 진료실·상담센터 보조도구와 부모교육 패키지를 우선한다.
4. 첫 유료 상품은 9,900~19,000원 PDF/워크북/계약서/설정 체크리스트 번들로 한다.
5. 웹앱 구독은 파일럿 후 전환한다.
6. 자동 사용량 수집과 강제 차단은 P2 이후 정책 검토 전까지 홍보하지 않는다.

1. 앱스토어 출시 여부

5. 전문가 계정과 상담자 대시보드
6. 기관용 라이선스 가격

## 20. 최종 실행 문장

우리집 디지털 약속의 첫 버전은 자녀를 더 강하게 감시·차단하는 앱이 아니라, 가족이 디지털 규칙을 덜 싸우며 운영하도록 돕는 코칭 제품이어야 한다. 4주 MVP는 계약서, 부모교육, 자녀 참여, 대체활동, 자기조절 연습 기록, 주간 리뷰를 먼저 검증한다. 자동 감시·차단·위험 탐지는 정책·개인정보·임상 안전 검토 전까지 후순위 별도 트랙으로 분리한다.
