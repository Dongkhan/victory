## 주요 산출물 범위

- T12~T18 기획/콘텐츠/프로토타입/스타터팩/QA 산출물을 이 폴더에 동기화했습니다.
- `templates/`에는 가족 디지털 계약서, Family Link·Screen Time 설정 체크리스트, 추가시간 요청서, 회복 플랜, 주간 리뷰지, 부모 1주 시작 가이드, 표지/사용안내 Markdown이 포함됩니다.
- 프로토타입은 정적 HTML 단일 파일이며, 실제 의료·상담·OS 제어 기능을 수행하지 않는 P0 검증용 샘플입니다.
