# QA P0 안전·모바일 UX 리뷰

검토 범위:
- T16 프로토타입: `index.html`, `CHANGELOG_P0_PROTOTYPE.md`
- T17 출력물: `STARTER_PACK_README_KO.md`, `templates/*.md`, `family-digital-starter-pack-markdown-ko.zip`

검토 기준:
- 금지 표현과 과장 주장
- 우회 힌트·우회 절차 제공 여부
- 진단·치료 주장 여부
- 부모 과잉통제 유도 여부
- 아동 개인정보·민감정보 위험
- 하단 탭 겹침과 모바일 접근성
- 죽은 버튼·토스트만 있는 주요 액션
- 로컬 샘플 상태와 실제 수집/전송 기능의 구분

## 결론

P0 프로토타입과 스타터팩은 전반적으로 “감시·처벌·진단·치료”가 아니라 “가족 약속·설명·회복·주간 리뷰” 포지션을 유지하고 있다. 자해·자살, 폭력, 학대, 심한 절망감 등 위기 상황은 앱 규칙 조정보다 보호자·전문가·응급 도움을 우선하라는 안전 문구가 포함되어 있다.

다만 QA 중 세 가지는 직접 수정했다.

1. 프로토타입의 `규칙 다시 추천` 버튼이 토스트만 띄우는 죽은 버튼에 가까워 실제 규칙 초안이 바뀌도록 수정했다.
2. 칩과 하단 탭이 `div` 클릭 요소라 키보드 접근성이 약했다. `role="button"`, `tabindex="0"`, Enter/Space 키 동작, focus-visible outline을 추가했다.
3. 스타터팩 일부 문구의 우회 관련 세부 로그 표현과 `비밀번호` 표현이 오해될 수 있어 `우회 여부를 캐내는 세부 로그`, `보호자 암호 공유 금지와 설정 변경 권한 설명`으로 완화했다.

## 직접 수정한 파일

- `index.html`
  - `.chip`, `.tab`에 키보드 접근성 부여
  - focus-visible 스타일 추가
  - `규칙 다시 추천` 토스트-only 동작 제거
  - `다른 안전 초안 보기` 버튼으로 변경하고 실제 규칙 초안이 전환되도록 구현
- `STARTER_PACK_README_KO.md`
  - 우회 관련 세부 로그 표현을 `우회 여부를 캐내는 세부 로그`로 수정
- `templates/family-link-screen-time-checklist-ko.md`
  - 우회 관련 세부 로그 표현 완화
  - `비밀번호/설정 변경 권한`을 `보호자 암호/설정 변경 권한 설명`으로 수정
- `templates/family-digital-contract-ko.md`
  - `비밀번호와 설정 변경 권한`을 `보호자 암호 공유 금지와 설정 변경 권한 설명`으로 수정
- `family-digital-starter-pack-markdown-ko.zip`

## 남은 권고

- 실제 서비스 단계에서는 localStorage만으로는 보호자-자녀 동의 상태와 데이터 삭제/보관 정책을 충분히 설명하기 어렵다. 서버 연동 전 별도 개인정보 처리방침, 아동/청소년 동의 절차, 보호자 권한 범위를 다시 작성해야 한다.
- 위기 문구는 현재 안전하지만 실제 앱에서는 지역별 긴급 연락처와 보호자 알림 범위를 정책적으로 정해야 한다.
- 위치 공유는 공식 보호 도구의 항목으로만 다루고 있으나 민감 기능이므로 실제 제품에서는 기본값을 꺼두고 목적·보존·공유 범위를 별도 동의로 분리하는 것이 안전하다.
- 인쇄용 템플릿은 Markdown 기준으로 안전하지만 PDF 변환 시 작은 글씨와 체크박스 간격을 별도 확인해야 한다.
