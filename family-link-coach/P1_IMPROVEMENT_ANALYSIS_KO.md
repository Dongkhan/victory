# 우리집 디지털 약속 P1 개선안 분석

작성일: 2026-05-25
대상: Family Link를 대체하지 않고 보완하는 가족 디지털 습관 코칭 앱
현재 상태: P0 정적 모바일 웹 프로토타입 완성 후 P1 개선 범위 정의

---

## 1. 핵심 판단

Family Link의 부족한 지점은 차단 기능 자체가 아니라, 가족이 그 차단 기능을 어떻게 합의하고 운영하는지에 있다. 따라서 P1 개선 방향은 더 강한 잠금이나 우회 탐지가 아니라 다음 세 가지에 집중한다.

1. 가족 약속을 실제 Family Link 설정 항목으로 번역한다.
2. 자녀가 규칙 운영에 참여하고 자율권을 회복할 수 있는 경로를 보여준다.
3. 부모가 종료 갈등, 추가시간 요청, 위반 이후 대응을 덜 감정적으로 처리하도록 돕는다.

한 줄 방향:

> Family Link는 기기를 제한하고, 우리집 디지털 약속은 그 제한을 덜 싸우고 오래 지키게 만든다.

---

## 2. Family Link 대비 보완 영역

| 영역 | Family Link가 제공하는 것 | 남는 문제 | 우리집 디지털 약속 개선안 |
|---|---|---|---|
| 시간 제한 | 일일 한도, 다운타임, 학교시간 | 몇 분이 적절한지 부모가 모름 | 자녀 상황 기반 첫 주 규칙 초안 |
| 앱 제한 | 앱별 허용·제한 | 카톡, 학습앱, 안전연락 예외 판단이 어려움 | 항상 허용 연락·예외 앱 체크리스트 |
| 추가시간 | 부모가 보너스 시간 부여 | 떼쓰기와 협상으로 흐르기 쉬움 | 이유·시간·마무리 행동이 포함된 요청서 |
| 사용량 확인 | 앱 사용 요약 | 사용량을 보고 비난·처벌로 흐를 수 있음 | 주간 리뷰와 회복 플랜 중심 해석 |
| 위치/안전 | 위치 확인, 연락처 관리 | 감시로 받아들여질 수 있음 | 목적·공유범위·기본 안전연락 분리 |
| 자녀 참여 | 제한적 | 아이가 통제당한다고 느낌 | 자녀 목표, 이해 확인, 자율권 회복 단계 |

## 3. P1 우선 개선 기능

## 3.1 가족 약속 → Family Link 설정 번역기

목적: 부모가 만든 가족 규칙을 실제 공식 보호 도구 설정 항목으로 옮기기 쉽게 한다.

입력:

- 취침 전 사용 문제
- 게임 마무리 문제
- 숏폼 과사용
- 숙제 시작 지연
- 항상 허용해야 하는 연락·학습 앱
- 평일/주말 차이

출력 예:

```text
가족 약속: 평일 밤 10시에는 거실 충전대에 둔다.
Family Link에서 확인할 항목: 취침시간, 항상 허용 앱, 알람 대체 방법, 부모-자녀 설명 완료.
```

주의:

- 공식 보호 도구의 설정을 대신 조작하지 않는다.
- 우회법, 취약점, 삭제 방지, 몰래 감시 기능은 제공하지 않는다.
- “공식 앱에서 부모가 직접 확인할 항목”으로 표현한다.

## 3.2 자녀 자율권 회복 단계

목적: 규칙을 지키는 이유가 단순 처벌 회피가 아니라 자율권 회복이라는 점을 보여준다.

단계 예:

```text
1단계: 부모가 함께 확인
2단계: 종료 전 스스로 알림 말하기
3단계: 추가시간 요청서를 스스로 작성
4단계: 주간 리뷰에서 예외 규칙 제안
5단계: 일부 앱 제한을 완화할 수 있는 조건 검토
```

주의:

- 자율권 회복은 자동 보상이 아니라 가족 리뷰에서 검토하는 조건이다.
- 수면, 식사, 안전 연락, 기본 애정은 보상·처벌 거래 대상이 아니다.

## 3.3 종료 갈등 대화 코치

목적: Family Link 제한 종료 시점의 부모-자녀 말싸움을 줄인다.

상황별 스크립트:

- “5분만 더”
- “친구들이랑 하는 중”
- “나만 못 하게 해”
- “숙제 다 했어”
- “엄마가 마음대로 바꿨어”

권장 구조:

```text
인정 → 규칙 확인 → 다음 협상 시점 제시 → 회복 행동
```

예:

```text
지금 끊기 아쉬운 건 알아. 그래서 마무리 시간을 둔 거야. 오늘은 계약대로 종료하고, 일요일 리뷰 때 시간이 부족했는지 같이 조정하자.
```

## 3.4 4주 파일럿 측정

목적: 제품의 핵심 가치가 실제로 갈등 감소인지 확인한다.

핵심 지표:

- 첫 계약서 생성 완료율
- Family Link 설정 체크 완료율
- 첫 주 리뷰 완료율
- 추가시간 요청이 말싸움 대신 사용된 횟수
- 종료 갈등 빈도 자기보고 변화
- 자녀가 “규칙이 이해된다”고 답한 비율
- 부모가 “덜 싸웠다”고 답한 비율

## 4. 이번 프로토타입에 즉시 반영할 개선

이번 커밋에서는 P1 전체를 구현하지 않고, P0 프로토타입 안에 다음 세 가지 가시적 개선을 추가한다.

1. 설정 체크리스트 화면에 “가족 약속 → 공식 보호 도구 설정 번역” 카드 추가
2. 홈 화면에 “자율권 회복 단계” 카드 추가
3. 리뷰 화면에 “4주 파일럿 측정 항목” 카드 추가

의도:

- 사용자가 제품의 차별점을 첫 사용 흐름에서 바로 이해한다.
- 단순 문서 묶음이 아니라 실제 반복 사용 제품으로 확장될 수 있음을 보여준다.
- 기술적 차단 기능 없이도 Family Link 보완 가치가 드러난다.

## 5. 보류할 개선

다음은 P1 이후로 미룬다.

- 부모/자녀 계정 분리
- Push 알림
- 실제 서버 저장
- 결제
- Android UsageStatsManager 연동
- iOS Screen Time API PoC
- 상담자 대시보드
- 자동 사용량 분석

이유: P0/P1 초반에는 제품 가치 검증보다 기술 구현이 앞서면 위험하다. 우선 가족 계약·추가시간 요청·회복 플랜·주간 리뷰가 실제 갈등을 줄이는지 확인해야 한다.

## 6. 다음 실험 제안

대상:

- 초등 고학년~중학생 자녀가 있는 5가정
- 이미 Family Link 또는 Screen Time을 쓰고 있거나 도입하려는 가정

방법:

1. 첫 방문에서 계약서 생성
2. 부모가 공식 보호 도구 설정 체크
3. 1주 동안 추가시간 요청과 회복 플랜 사용
4. 주간 리뷰 1회 진행
5. 부모·자녀 각각 5문항 피드백

성공 기준:

```text
5가정 중 3가정 이상이 “기존보다 말싸움이 줄었다”고 답하면 P1 계정 연동으로 진행한다.
5가정 중 3가정 이상이 “문서가 너무 많고 앱을 다시 열 이유가 약하다”고 답하면 Push나 계정 연동보다 홈 화면 단순화와 요청 기능을 먼저 개선한다.
```
