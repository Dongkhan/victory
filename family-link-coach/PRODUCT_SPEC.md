# 디지털 패밀리 코치 v1 제품 기획서

## 1. 제품 정의

Family Link를 대체하거나 우회하는 앱이 아니라, Family Link와 병행해 부모-자녀의 디지털 사용 규칙을 발달·정신건강·가족갈등 관점에서 설계하고 실행하도록 돕는 앱.

한 줄 정의:

> Family Link의 기술적 통제를 부모-자녀 계약, 맞춤 규칙, 갈등 대화, 주간 리뷰로 확장하는 가족 디지털 습관 코치.

## 2. 해결할 문제

1. 부모가 Family Link 설정값을 어떻게 잡아야 할지 모른다.
2. 아이는 통제당한다고 느끼고, 종료 시점에 갈등이 커진다.
3. 사용시간이 학습, 연락, 게임, 숏폼, 창작 등 목적별로 구분되지 않는다.
4. ADHD, 불안, 우울, 수면 지연, 게임 몰입 등 아이 특성이 반영되지 않는다.
5. 위반 후 대응이 장기 압수나 말싸움으로 흘러간다.
6. 규칙이 가족 내에서 기록·리뷰·수정되지 않는다.

## 3. v1 핵심 가치

- 몰래 감시하지 않는다.
- 위치추적과 메시지 열람은 기본 기능에서 제외한다.
- 아이에게 규칙과 이유를 보여준다.
- 아이가 목표 선택, 추가시간 요청, 규칙 수정 제안, 주간 리뷰에 참여하게 한다.
- 제한은 처벌이 아니라 자기조절 훈련과 자율권 회복 단계로 설명한다.
- 처벌보다 회복 경로를 제공한다.
- 부모가 바로 말할 수 있는 짧은 대화문을 제공한다.
- Family Link 설정을 직접 우회하지 않고, 안전한 수동 설정 가이드를 제공한다.

## 4. v1 기능 범위

### 4.1 부모 온보딩 설문

입력 항목:

- 아이 나이/학년
- 주요 문제: 게임, 숏폼, 수면, 몰래 사용, 숙제 지연, 종료 분노
- 평일/주말 생활패턴
- 부모의 우선 목표: 수면, 학습, 갈등 감소, 게임 조절, 숏폼 감소
- 허용해야 하는 앱: 전화, 문자, 카카오톡, 학습앱 등

### 4.2 아이 유형 분석

분류 예시:

- 전환 어려움형
- 수면 지연형
- 게임 몰입형
- 숏폼 과사용형
- 불안/연락 의존형
- 반항/갈등형
- 무기력/우울 위험형

주의:

- 진단명을 부여하지 않는다.
- 생활지도와 부모교육 목적의 패턴 설명으로 제한한다.

### 4.3 맞춤 규칙 생성

생성 항목:

- 평일 총 사용시간
- 주말 총 사용시간
- 앱별 제한
- 취침시간
- 항상 허용 앱
- 추가시간 요청 규칙
- 위반 후 회복 규칙
- 보상 규칙

### 4.4 가족 디지털 계약서

출력:

- 부모-아이 공동 약속
- 서명란
- 주간 리뷰 날짜
- PDF 저장
- 인쇄/공유용 문서

### 4.5 갈등 상황 스크립트

상황별 문장:

- 그만하라고 해도 안 끊음
- 몰래 사용함
- 친구들은 다 된다고 함
- 숙제 전에 게임함
- 밤에 몰래 봄
- 부모가 화를 냄

### 4.6 Family Link 설정 가이드

출력:

- 추천 설정값
- Family Link 메뉴 경로
- 앱별 제한 순서
- 취침시간 설정 순서
- 항상 허용 앱 설정
- 앱 설치 승인 설정

## 5. v2 기능

- 추가시간 요청/승인
- 보상 포인트
- 주간 리뷰 저장
- 알림
- 가족별 여러 자녀 관리
- 계약서 버전 관리

## 6. 대체활동 기반 개입

상세 설계는 `ALTERNATIVE_ACTIVITY_SYSTEM.md`를 기준으로 한다.

핵심 기능:

- 소아: 놀이, 신체활동, 감각·진정 활동, 부모와 10분 놀이, 생활 미션 중심
- 청소년: 가치기반 활동, 직업적 포부, 창작, 운동, 진로 프로젝트, 회복 루틴 중심
- 연령/에너지/시간/날씨/부모 참여 가능성/문제 유형 기반 추천
- 활동 시작·완료·일부 완료·건너뜀·거부 체크
- 활동 완료와 토큰 지급 자동 연동
- 활동 전후 기분, 화면 갈망, 통제감 변화 기록
- 주간 리뷰에서 성공 활동, 거부 활동, 기분 개선 활동을 요약

## 7. v3 기능

Android 중심 자체 제어 기능 검토:

- UsageStatsManager 기반 앱 사용시간 조회
- DevicePolicyManager 기반 제한
- Foreground Service 기반 알림
- 취침시간 잠금
- 허용앱/제한앱 목록

정책 리스크:

- Accessibility Service를 앱 차단 목적으로 쓰면 Google Play 심사 문제가 생길 수 있다.
- 메시지 내용 감시, 몰래 위치추적, 우회 기능은 제외한다.

## 9. 보상 시스템 설계

상세 설계 문서: `SELF_MONITORING_TOKEN_ECONOMY_DESIGN.md`

핵심 원칙:

- 보상은 사용시간 감소의 대가가 아니라 자기조절 행동의 기록이다.
- 토큰 획득은 사용 전 목적 체크, 종료 전환, 취침 전 충전, 대체활동, 회복 미션, 주간 리뷰에 연결한다.
- 토큰 사용은 주말 소량 추가시간, 가족 활동 선택권, 취미·창작 활동, 규칙 수정 제안권 중심으로 제한한다.
- 수면, 식사, 안전, 기본 애정, 긴급 연락, 치료·상담·약물은 토큰 거래 대상에서 제외한다.
- ADHD, 불안, 우울, 게임몰입, 숏폼 과사용 패턴별로 강화 대상과 차감 규칙을 다르게 적용한다.
- 전량 몰수, 과잉보너스, 형제 비교, 현질·가챠 보상은 금지한다.

## 10. 부모교육 커리큘럼

상세 설계 문서: `PARENT_EDUCATION_CURRICULUM_KO.md`

핵심 원칙:

- 부모 정보 수준을 초급/중급/고급으로 나누고, 같은 주제도 카드/가이드/PDF 난이도를 다르게 제공한다.
- 교육 내용은 디지털 습관이 수면·주의·감정조절·가족갈등·학습에 주는 영향을 생활 규칙으로 번역한다.
- Family Link 설정은 일일 한도, 앱별 제한, 다운타임/수업시간, 시간 무제한 앱, 구매 승인, 보너스 시간 원칙으로 구조화한다.
- 콘텐츠 형식은 1분 카드, 5분 가이드, 부모/아이/전문가용 PDF 워크북으로 분리한다.
- 부모-자녀 대화 스크립트는 감시·단속보다 약속·회복·주간 리뷰를 강화하는 문장으로 제한한다.
