# 러닝퀘스트 · Run Quest

**어디서 출발하든** 달리거나 걸어서 지나간 자리가 칠해지는 탐험 러닝 앱 프로토타입.
단일 HTML 파일이며 빌드·설치·계정·서버·광고가 없습니다.

- 최신 실행본: `prototype/v0.5.html`
- 웹 설치(PWA): 배포 주소의 `/run` 을 폰 브라우저로 열고 '홈 화면에 추가' (iPhone 포함)
- 이전 버전: `prototype/v0.4.html` (원버튼·길 닳기·코스), `prototype/v0.3.html` (보물·시즌·사진 핀·고스트),
  `prototype/v0.2.2.html` (추격자·자동 종료),
  `prototype/v0.2.1.html` (전역 격자·다중 거점), `prototype/v0.2.html` (집 기준 상대 격자),
  `prototype/v0.1.html` (게임화 MVP, 지도 없음)
- 짧은 주소: `/run`, `/running`, `/run-quest`

## v0.2가 푸는 문제

초보 러너가 3주 안에 그만두는 이유는 동기 부여 장치가 없어서가 아니라,
**같은 골목을 도는데 진전이 안 보이고**, 목표를 앱이 정해 주며,
성취의 증거가 기록 목록의 한 줄뿐이기 때문입니다.
v0.2는 보상 대신 **되돌릴 수 없이 쌓이는 지도**를 성취의 중심에 둡니다.

| 축 | 장치 |
| --- | --- |
| 집 주변이 강점이 됨 | 지나간 40m 칸이 영구히 칠해짐. 멀리 갈 필요 없이 안 가본 골목이면 충분 |
| 성취가 그림으로 남음 | "이번 달 12km" 대신 "726칸 개척 · 구역 22/24 발견" |
| 매번 다른 이유가 생김 | 지도를 읽어 가장 덜 간 방향으로 그날의 미션을 만듦 |
| 누구나 | 걷기도 같은 칸을 칠함. 15초/50m 미만 기록만 저장에서 제외 |

## 구조

### 전역 탐험 격자 (v0.2.1)
칸 키가 **절대 위경도**에서 나옵니다(`cellKeyOf`). 위도 밴드로 먼저 나누고 그 밴드의 경도 폭으로 나눠
지구 어디서나 40m 칸이 일정하게 떨어집니다. 그래서 **출발점을 미리 정할 필요가 없고**,
거점을 옮기거나 여행을 가도 이미 칠한 지도가 그대로 남습니다.
GPS 점이 듬성듬성해도 두 점 사이를 반 칸 간격으로 훑어(`paintSegment`) 지나간 칸을 모두 채웁니다.
도로망 데이터가 없어도 되므로 골목·공원·하천길·전 세계 어디서나 그대로 동작합니다.

### 거점(places)과 24개 구역
거점은 **여러 개** 둘 수 있습니다 — 우리 동네, 회사 앞, 부모님 댁, 여행지.
각 거점마다 **8방위 × 거리 3단계**(500 / 1000 / 1500m)로 24개 구역이 생기고,
구역별 목표 칸(12 / 20 / 28)을 채우면 `발견 → 탐험 중 → 정복`으로 올라갑니다.
거점 앞 80m는 어느 구역에도 속하지 않습니다 — 제자리에서 방위만 바꿔 '발견'되는 걸 막기 위해서입니다.

거점은 **선택 사항**입니다. 없어도 달리기와 지도 칠하기는 그대로 되고,
달리기를 마쳤을 때 출발점이 저장된 거점에서 1.2km 넘게 떨어져 있으면
"여기, 자주 오나요?" 카드로 저장을 제안합니다. 거점을 지워도 칠한 칸은 남습니다.

### 모드
| 모드 | 내용 |
| --- | --- |
| 탐험 러닝(기본) | 현재 위치에서 안 밟은 칸이 많은 방향을 주기적으로 안내 |
| 자유 달리기 | 내 페이스대로, 1km 스플릿 |
| 인터벌 챌린지 | 워밍업 3분 → 빠르게 1분 / 회복 2분 × 5 → 쿨다운 3분 |
| 스토리 러닝(도전) | 추격자가 **지도 위에서 내 경로를 따라** 쫓아온다. **차 없는 넓은 코스 전용**임을 명시하고 도전 섹션으로 분리 |

#### 지도 위 추격자 (v0.2.2)
추격이 시작되면 70m 뒤에서 추격자가 나타나 **내가 지나온 경로를 그대로 따라옵니다**(`pointBack`).
간격은 `시작 여유 + 내가 간 거리 − 추격자 속도 × 경과시간`이라, 페이스를 올리면 벌어지고 늦추면 좁혀집니다.
남은 거리(m)가 배너와 지도에 실시간으로 뜨고, 25m 안으로 들어오면 배너와 지도 테두리가 붉게 변합니다.
간격이 0이 되면 그 자리에서 추격이 끝나고(잡힘), 시간을 버티면 따돌린 것으로 처리합니다 —
**화면에 보이는 간격이 곧 판정 기준**이며, 잡혀도 벌점은 없습니다.

### 성취 재설계 (v0.1 대비)
- 매일 스트릭 → **주 단위 스트릭**(주 2회면 유지) + **한 주 자동 보호**
- 숫자 배지 → 이야기 배지 추가: `다시 시작`(2주 쉬고 복귀), `팔방 탐험`, `첫 구역 정복`, `사진 5장`
- 코인 폐지 → 성취 단위를 **칸**으로 일원화, 미션 보상은 XP
- 완료 화면에 **기록 카드**(PNG) 생성 — 칠해진 지도 + 오늘 수치

### 무동작 자동 종료 (v0.2.2)
마지막으로 움직인 시각을 **실제 시각**으로 들고 있어서, 일시정지 중이거나 GPS 신호가 없어도 흐릅니다.
5분 동안 움직임이 없으면 자동으로 종료하고 저장하며, 4분에 "1분 뒤 자동으로 종료할게요"라고 미리 알립니다.
설정에서 끌 수 있고(기본 켜짐), 자동 종료된 기록이 너무 짧으면 저장하지 않고 그 이유를 알려줍니다.

## v0.5 — 실사용 준비판

새 재미 요소가 아니라, 지금 있는 것을 **실제 폰에서 쓸 수 있게** 만드는 판입니다.

### 화면이 꺼져도 추적 (안드로이드)
`@capacitor-community/background-geolocation`으로 포그라운드 서비스를 띄워 화면이 꺼지거나 앱이 뒤로 가도 위치를 받습니다.
달리는 동안 상단에 "러닝퀘스트 · 달리는 중" 알림이 떠 있고, 종료는 앱에서 합니다.
`capacitor.config.json`의 `android.useLegacyBridge: true`는 이 플러그인의 요구사항입니다(5분 뒤 갱신 끊김 방지).

- 앱 매니페스트에는 `ACCESS_BACKGROUND_LOCATION`을 넣지 않았습니다. 앱이 앞에 있을 때 서비스를 시작하므로 필요 없고, 스토어 심사 부담만 늘립니다
- Android 13+에서 알림 권한을 거부하면 상단 알림만 안 보이고 추적은 계속됩니다
- 플러그인이 없는 환경(브라우저·PWA)에서는 자동으로 `watchPosition`으로 폴백합니다. 이때는 화면을 켜두어야 합니다

### 음성이 실제로 나옴
`@capacitor-community/text-to-speech`로 네이티브 TTS를 씁니다(ko-KR). 추격 경고처럼 급한 말은 앞의 말을 끊고(queueStrategy 0), 나머지는 순서대로 말합니다.
브라우저에서는 `speechSynthesis`로 폴백합니다.

### 화면 켜두기
`@capacitor-community/keep-awake`. 백그라운드 추적이 있어 필수는 아니지만, 흘끗 볼 때 유용합니다.

### 번들러 없이 네이티브 호출
앱이 단일 HTML이라 플러그인 JS를 import하지 않습니다. 대신 Capacitor 코어가 WebView에 주입하는
`Capacitor.nativePromise` / `Capacitor.nativeCallback`을 직접 부르고, `Capacitor.PluginHeaders`로 플러그인 존재를 확인합니다.
프로토타입 HTML과 앱에 들어가는 HTML이 **완전히 같은 파일**로 유지되는 이유입니다.

### 가져오기 — 폰을 바꿔도 지도가 따라온다
'나 → 내 데이터 → 가져오기(JSON)'. 옛 버전(v1~v5) 내보내기 파일을 모두 받아 **합칩니다**:
겹치는 달리기는 한 번만, 같은 칸은 방문 횟수를 더하고, 거점·코스·배지는 없는 것만 추가, XP는 큰 쪽.

### 저장 용량 관리
경로 좌표를 세션당 300→120점으로 줄이고, 최근 60회만 좌표를 보관합니다(통계·핀·코스는 그대로).
용량이 차면 오래된 사진 → 오래된 경로 순으로 비우고, '내 데이터'에 사용량을 표시합니다.

### 코스 형태 매칭
세션마다 **8방위별 이동 거리 분포**를 지문으로 남기고, 코사인 유사도 0.8 이상일 때만 같은 코스로 묶습니다.
같은 출발점에서 다른 방향으로 도는 두 코스가 더는 합쳐지지 않습니다. 지문이 없는 옛 기록은 종전처럼 출발점·거리로만 봅니다.

### GPS 스무딩
정확도에 따라 가중치를 달리한 지수이동평균(10m 이하 0.7 / 20m 이하 0.5 / 그 외 0.35)으로 지도에 찍히는 위치의 떨림을 줄이고,
정확도 30m를 넘는 신호로는 칸을 칠하지 않습니다(거리 자체는 45m까지 인정). 지도 다시 그리기도 최대 0.4~1초에 한 번으로 제한했습니다.

### PWA
`manifest.webmanifest` + `sw.js`로 홈 화면 설치와 오프라인 실행을 지원합니다. 앱(Capacitor) 안에서는 서비스 워커를 등록하지 않습니다.
iPhone은 이 경로로만 쓸 수 있고, 백그라운드 추적은 되지 않습니다(화면을 켜두어야 함).

### 테스트가 저장소 안으로
`tests/test_run_quest_browser_smoke.py`가 실제 Chromium에서 온보딩→원버튼 시작→보물→종료→거점 저장→사진 핀→가져오기 합치기→재시작 유지까지 돌립니다.
`.github/workflows/run-quest-web.yml`이 푸시마다 정적 테스트와 함께 실행합니다.

## v0.4 — 원버튼 시작과 '반복해도 쌓이는' 보상

### 🚀 원버튼 시작
첫 화면(동네 탭) 맨 위에 **바로 달리기 시작** 버튼이 있습니다. 마지막에 쓴 모드·목표·데모 설정을
기억했다가 그대로 시작하고, 버튼 아래에 "🧭 탐험 러닝 · 목표 없음 로 바로 시작해요"처럼 미리 보여줍니다.
설정을 바꾸고 싶을 때만 아래의 '모드·목표 고르고 시작'으로 들어가면 됩니다.

### 👣 길 닳기 — 같은 길을 다시 밟을수록 진해진다
칸 값에 **방문 횟수**를 함께 담습니다(`첫 개척일 * 1000 + 방문 수`). 자릿수 세 개만 늘려 저장 비용은 그대로입니다.

- 다시 밟을 때마다 그 칸이 밝아집니다(1회 → 15회에서 최대). 자주 다니는 길이 지도에서 빛나기 시작합니다
- 재방문에도 XP가 붙고(`wearGain`), 열 번째 방문에는 "이 길, 열 번째예요. 이제 내 길이네요"라고 알려줍니다
- **한 번의 달리기에서 같은 칸은 한 번만** 셉니다 — 제자리 반복으로 부풀릴 수 없습니다
- 첫 개척일은 절대 덮어쓰지 않아 '언제 처음 왔는지'는 그대로 남습니다

### 🛤️ 코스 — 반복이 등급이 된다
같은 자리(150m 이내)에서 비슷한 거리(±18%)로 다시 달리면 **같은 코스**로 묶입니다.

| 완주 | 등급 |
| --- | --- |
| 1회 | 🌱 새 코스 |
| 3회 | 🌿 익숙한 코스 |
| 10회 | 🛤️ 단골 코스 |
| 30회 | 🏅 내 코스 |
| 100회 | 👑 전설의 코스 |

기록 탭의 '내 코스'에서 완주 횟수·최고 페이스·최근 페이스·다음 등급까지 남은 횟수를 봅니다.
코스에는 직접 이름을 붙일 수 있습니다("아침 한강 루프").

### 🚀 자체 최고 기록
다니던 코스에서 페이스를 갱신하면 완료 화면에 **"이 코스 자체 최고 기록! (km당 N초 단축)"**이 뜹니다.
노이즈로 인한 가짜 기록을 막기 위해 0.5초 이상 빨라져야 인정하고, 첫 완주는 PR로 치지 않습니다.
고스트도 **최근 세 번 중 가장 빨랐던 나**를 상대로 삼아, 반복할수록 겨룰 상대가 함께 올라갑니다.

완료 화면에는 '익숙한 길 78% / 다시 밟은 칸 42개'처럼 **반복 자체가 성과로** 표시됩니다.

## v0.3에서 더해진 재미

### 🎁 보물 사냥
달리는 동안 지도에 보물이 최대 3개 떠 있습니다. 그 칸을 밟으면 획득(+12~20 XP)하고 새 보물이 채워집니다.

스폰 규칙이 이 기능의 핵심입니다 — **이미 밟아본 칸에 붙어 있는, 아직 안 밟은 칸**에만 놓습니다.
내가 가본 길 바로 옆이라 실제로 갈 수 있는 곳이 보장되고(차도·물길로 유인하지 않음),
자연히 미개척 방향으로 끌려갑니다. 보물끼리는 120m 이상 떨어뜨려 한곳에 뭉치지 않게 합니다.
못 먹어도 그냥 사라지고, 설정에서 끌 수 있습니다.

### 🎨 시즌 색 (매달 새 레이어)
칸의 **첫 개척일은 절대 덮어쓰지 않고**, 이번 달에 방문한 칸을 따로 모읍니다(`S.map.season`, 달이 바뀌면 저절로 비워짐).
지도는 `오늘 개척(금) / 이번 달 방문(선명한 초록) / 그 외(가라앉은 청록)` 세 층으로 그려집니다.
다 칠한 동네도 "이번 달 색으로는 아직"이 되어 다시 뛸 이유가 생기고, 재방문은 새 칸으로 세지 않아 기록은 정직합니다.

### 📷 지도에 박히는 사진 핀
'오늘의 한 장'에 좌표가 붙어 지도에 핀으로 남습니다. 핀을 누르면 그날 기록이 열립니다.
지도가 기록판에서 앨범으로 바뀝니다. v0.2.x의 문자열 사진도 이관 시 좌표를 붙여 되살립니다.

### 🗣️ 실황 멘트
새 칸에 들어서면 "이 골목은 처음이에요", 지난달 길을 다시 밟으면 "이번 달 처음 오는 길이에요",
10칸·25칸마다 격려. 최소 45초 간격 제한이 있어 수다스럽지 않습니다.

### 👤 지난번 나 (고스트)
**같은 자리(150m 이내)에서 출발했던 가장 최근 달리기**를 골라, 그때의 평균 페이스로 함께 달립니다.
지도에 👤 마커와 `+23m / −15m / 나란히`가 뜨고, 나란히 달릴 땐 마커가 겹치지 않게 옆으로 비껴 그립니다.
완료 화면에 "지난번보다 +N m 앞"이 남습니다. 설정에서 끌 수 있습니다.

### 오늘의 한 장
세션마다 사진 한 장을 붙일 수 있습니다. 720px로 축소해 JPEG 0.6으로 저장하고 최근 20장만 보관합니다.
카메라·갤러리 모두 기기 안에서만 처리됩니다.

## 프라이버시

- 거점 좌표와 지도는 `localStorage("runquest.v5")`에만 저장되고 네트워크로 나가지 않습니다
  (앱에 `fetch`/`XHR`/`WebSocket`/`sendBeacon` 호출이 없습니다 — 테스트로 고정)
- 지도는 **중심점 기준 상대 좌표**로만 그려집니다. 기록 카드에도 좌표·주소·지도 타일이 없습니다(테스트로 고정)
- v0.2(`runquest.v2`) 데이터는 첫 실행 시 이관되며, 집 기준으로 저장돼 있던 칸을 전역 좌표로 변환해 **칠한 지도를 그대로 보존**합니다
- v0.1(`runquest.v1`) 기록은 그대로 이어받고, 지도는 비어 있는 채로 시작해 다음 달리기부터 칠해집니다

## 위치 권한이 없을 때

`데모 모드`를 켜거나 위치 권한이 거부되면 가상 경로 시뮬레이터로 전체 흐름을 그대로 체험할 수 있습니다.
거점도 데모 위치로 만들 수 있고, 그렇게 만든 기록은 목록에 `데모`로 표시됩니다.

## 안전

온보딩·달리기 준비·설정 세 곳에 안전 고지가 있습니다. 의료기기가 아니며 진단·치료를 대신하지 않습니다.
미션은 절대 무리한 속도를 요구하지 않으며, 속도를 강요하는 스토리 모드는 기본에서 내렸습니다.

## 접근성

`prefers-reduced-motion` 및 앱 내 토글, `:focus-visible` 아웃라인, 44px 이상 터치 타깃,
`aria-live` 코치/챌린지 안내, `role=tab`/`switch`/`dialog`, 라이트·다크 모드 대응.

## 안드로이드 APK

`capacitor-app/` 이 Capacitor 8 래퍼입니다. 웹 자산은 `prototype/v0.5.html` 한 벌을
`capacitor-app/www/index.html` 로 복사해 쓰며, 두 파일이 다르면 테스트가 실패합니다.

### 내려받기

`run-quest/**` 에 푸시가 들어가면 `.github/workflows/run-quest-android.yml` 가 APK를 빌드해
워크플로 아티팩트 `run-quest-debug-apk` 와 릴리스 태그 `run-quest-v0.5.0` 자산으로 올립니다.
디버그 서명 빌드라 사이드로딩 전용이며 Play 스토어 배포본이 아닙니다.

### 직접 빌드

필요: JDK 21, Android SDK(platform 36 / build-tools 36.0.0), Node 22+.

```bash
cd run-quest/capacitor-app
npm ci
npm run apk:debug          # www 복사 → cap sync → gradlew assembleDebug
# 결과: android/app/build/outputs/apk/debug/app-debug.apk
```

아이콘·스플래시는 외부 에셋 없이 생성됩니다: `npm run icons` (Pillow 필요).

### 네이티브 권한

| 권한 | 쓰임 |
| --- | --- |
| `ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION` | 거리·경로·지도 칠하기. 기기 밖으로 전송하지 않음 |
| `VIBRATE` | 새 칸·구역 발견 진동 |
| `INTERNET` | Capacitor 로컬 WebView 스킴(외부 통신 없음) |

GPS는 `required=false` 라 GPS 없는 기기에도 설치되며, 권한을 거부하면 데모 모드로 동작합니다.

### 안드로이드에서의 제약 (v0.5 이전)

v0.4까지는 WebView 한계로 음성이 무음이었고 화면이 꺼지면 추적이 끊겼습니다. v0.5에서 네이티브 플러그인으로 해결했습니다.
플러그인 3종은 이 세션에서 기기 테스트를 하지 못했으므로, 첫 실외 사용 때 상단 알림이 뜨고 화면을 끈 뒤에도 거리가 늘어나는지 확인해 주세요.
