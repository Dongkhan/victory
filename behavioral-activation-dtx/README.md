# Behavioral Activation DTx 프로젝트 초안

3번째 디지털치료제 프로젝트. 주제는 우울·무기력·회피 악순환을 겨냥한 행동활성화 기반 모바일 앱이다.

## 1. 한 줄 정의

**행동을 바꿔 기분을 기다리지 않고 삶의 강화 환경을 회복시키는, 정신건강의학과 외래 확장형 행동활성화 앱.**

## 2. 작업명

- 폴더명: `behavioral-activation-dtx`
- 제품 가칭: **ActivaCare**
- 내부 프로젝트명: **BA DTx**

## 3. 근거 수집 요약

### 3.1 Notion `디지털치료제` 폴더에서 반영한 내용

확인한 하위 축:

- 사전조사
- 시장조사
- 기획
- 프로토타입
- 디자인지침
- RelaxDTx 프로젝트 허브
- CBT-I DTx
- DTx 근거 업데이트
- DTx 제품 전략 보고서

핵심 반영점:

1. **DTx는 단독 앱보다 care extension 모델이 우선**
   - 사용자의 기존 방향성은 정신건강의학과 외래를 대체하는 앱이 아니라, 외래 사이의 행동 처방·모니터링·피드백을 담당하는 확장 도구다.
   - 행동활성화 앱도 같은 방식으로 설계한다. 환자는 앱에서 일일 활동 처방을 수행하고, 의사는 외래에서 활동-기분-회피 패턴을 빠르게 확인한다.

2. **B2C 단독보다 B2B/B2I/B2G 확장 가능성을 열어둔다**
   - 대학·기업 EAP·지역사회 정신건강사업·의료기관용 대시보드로 확장 가능하다.
   - 초기 MVP는 클리닉 내부 사용과 환자 자가관리 중심으로 제한한다.

3. **Relax Routine, CBT-I Care에서 이미 검증한 UX 자산을 재사용한다**
   - 따뜻한 ivory/sage 계열, 낮은 자극, 의료적이지만 차갑지 않은 톤.
   - 단일 HTML 프로토타입에서 검증했던 bottom navigation, 카드형 기록, 진행률 시각화 구조를 재사용한다.
   - 세션은 실제 완료된 경우에만 기록한다는 원칙을 유지한다.

4. **규제 전략은 wellness-first, medical-track-ready**
   - 초기 표현은 우울증 치료 효능을 직접 주장하지 않는 웰니스·진료 보조 도구로 둔다.
   - 다만 MFDS 디지털의료제품 분류·지정 규정, 시장즉시진입 의료기술 트랙, FDA/CMS의 디지털 정신건강기기 흐름을 고려해 추후 SaMD 전환 가능성을 열어둔다.

5. **개인화와 engagement가 핵심 차별화 포인트**
   - 2025–2026 DTx 근거 업데이트에서 개인화 알고리즘, 게임화, GenAI 코치, 장기 engagement가 반복적으로 중요하게 등장했다.
   - 행동활성화 앱은 단순 활동 목록 앱이 아니라 `사용자별 강화원·회피패턴·시간대·에너지 수준`에 맞는 적응형 활동 처방 앱이어야 한다.

### 3.2 DTx 근거 업데이트에서 반영한 내용

- 디지털 CBT guided self-help는 대규모 대학생 RCT에서 장기 효과 가능성을 보였다. 접근성·확장성 논리의 근거로 사용 가능하다.
- 개인화 게임 기반 디지털 중재는 무중재 대비 치료 반응·관해율을 높인 pilot RCT 근거가 있다. BA 앱의 보상·레벨·퀘스트 구조 설계 근거가 된다.
- GenAI 탑재 CBT 앱은 engagement 개선 가능성이 있다. 단, 초기 MVP에서는 GenAI를 핵심 치료 엔진이 아니라 안전한 코칭·요약·문장화 보조로 제한한다.
- Apple Watch HRV, Android Health Connect 등 생체·활동 데이터 연동은 후속 단계에서 가능하다. MVP에서는 수동 기록을 기본으로 한다.
- 국내 MFDS 디지털의료제품 규제 정비와 시장즉시진입 의료기술 흐름을 고려해, 문구·데이터·임상평가 설계를 처음부터 정돈한다.

### 3.3 Wiki/지식베이스의 행동활성화 관련 핵심

Obsidian REST API는 현재 접근이 불안정했다. `http://100.127.243.77:27123/vault/`는 private network 차단 또는 timeout, `localhost:8090/obsidian` 계열은 HTTP 500/timeout을 보였다. 대신 Notion/wiki 검색과 과거 세션 회상에서 확보된 행동활성화 관련 지식을 반영했다.

핵심 문서:

- `Lewinsohn (1974) — 우울증의 행동 모델 / 행동 활성화의 토대`

핵심 개념:

1. **우울증은 기분의 병이면서 동시에 강화 환경의 병이다**
   - Lewinsohn 모델은 우울증을 `반응-수반적 정적 강화(RCPR)의 결핍`으로 본다.
   - RCPR 감소 → 행동량 감소·수동성·위축 → 우울 정서 → 강화 기회 추가 감소의 순환이 생긴다.

2. **행동 변화가 인지·기분 변화를 끌어내는 outside-in 원리**
   - 기분이 나아질 때까지 기다리는 것이 아니라, 작고 실행 가능한 행동을 통해 강화 경험을 먼저 회복한다.

3. **강화 빈도는 세 변수에 좌우된다**
   - 잠재적 강화 활동의 수
   - 환경 내 강화 기회의 가용성
   - 강화를 끌어내는 개인의 기술

4. **임상 적용 포인트**
   - 활동 모니터링 + 단계적 활동 증가
   - 숙달감과 즐거움의 두 축으로 활동 처방
   - 위축형 우울, 노인 우울, 청소년 우울에서 BA 단독 또는 보조 개입 가능
   - 짧은 외래에서도 `이번 주 한 가지 활동 처방`으로 적용 가능

5. **기존 Relax Routine 로드맵에서의 BA 정의**
   - 활동 모니터링
   - 가치 기반 활동 스케줄링
   - 회피 패턴 분석
   - 무기력-반추 악순환 차단
   - Jacobson, Dimidjian, Ekers 계열 근거를 임상 근거 축으로 사용

## 4. 문제 정의

외래 우울·불안 환자는 진료실에서는 변화 의지가 생겨도, 일상으로 돌아가면 다음 문제가 반복된다.

- 무엇을 해야 할지 구체적 행동으로 번역되지 않는다.
- 기분이 나아져야 행동할 수 있다고 느낀다.
- 회피 행동은 단기적으로 편하지만 장기적으로 강화 기회를 줄인다.
- 의사는 다음 외래까지 환자의 실제 생활 패턴을 거의 볼 수 없다.
- 환자는 실패 경험이 누적되며 자기비난과 무력감이 강화된다.

따라서 앱의 핵심 임무는 `기분 추적`이 아니라 **강화 가능한 행동을 작게 설계하고, 실행하고, 피드백하며, 외래 진료에 연결하는 것**이다.

## 5. 대상 사용자

### 5.1 1차 대상

- 정신건강의학과 외래에서 경도~중등도 우울, 무기력, 회피, 생활 리듬 붕괴를 보이는 성인 환자
- 약물치료 중이나 일상 행동 변화가 정체된 환자
- 인지 재구성보다 구체적 행동 처방이 더 잘 맞는 환자

### 5.2 2차 대상

- 청소년 우울·무기력
- 불면 동반 우울 환자
- 직장인 번아웃·회피 패턴
- 퇴원 후 지역사회 복귀 환자

### 5.3 제외 또는 주의 대상

- 급성 자살위험, 정신병적 증상, 조증/경조증 의심, 중증 물질사용, 급성 외상 위기
- 이 경우 자동 행동 처방보다 임상가 평가와 위기 개입이 우선이다.

## 6. 임상 모델

### 6.1 기본 루프

```text
강화 감소
→ 활동 감소·회피 증가
→ 우울·무기력·반추 증가
→ 더 적은 활동과 사회 접촉
→ 강화 기회 추가 감소
```

앱은 이 루프를 다음 방식으로 끊는다.

```text
현재 활동·기분·회피 기록
→ 강화 가능한 작은 행동 선택
→ 일정에 배치
→ 실행 체크
→ 숙달감·즐거움·에너지 변화 기록
→ 다음 처방 개인화
→ 외래 피드백
```

### 6.2 마음의 4법칙과의 연결

행동활성화 앱은 `마음의 4법칙` 중 특히 다음 축에 해당한다.

- 감정은 직접 명령하기 어렵지만 행동·환경 조작을 통해 간접적으로 변한다.
- 회피는 단기 안정감을 주지만 장기적으로 삶의 강화원을 축소한다.
- 반복되는 작은 행동은 자기개념과 예측 모델을 바꾼다.
- 외부 구조가 무너진 환자에게 앱은 임시 외골격 역할을 한다.

## 7. MVP 핵심 기능

### 7.1 온보딩

- 현재 어려움 선택: 무기력, 흥미 저하, 회피, 외출 감소, 사회적 고립, 수면 리듬 붕괴, 집안일 방치, 일/학업 지연
- PHQ-9 또는 간단 우울 체크
- 자살위험 문항 포함
- 조증/경조증 간단 스크리닝
- 사용 목적 선택: 기분 회복, 생활 리듬, 외출, 대인관계, 일/공부 복귀, 건강관리

### 7.2 활동 모니터링

- 하루 활동 타임라인
- 활동 카테고리:
  - 자기관리
  - 집안일
  - 신체활동
  - 관계/연락
  - 일/학업
  - 즐거움
  - 의미/가치
  - 회복/휴식
- 각 활동 후 기록:
  - 실행 여부
  - 기분 전/후
  - 에너지 전/후
  - 즐거움 0–10
  - 숙달감 0–10
  - 회피 충동 0–10

### 7.3 활동 처방

- `2분 행동`, `10분 행동`, `30분 행동`으로 난이도 분리
- 환자 상태에 따라 작게 시작
- 예시:
  - 창문 열고 2분 햇빛 보기
  - 샤워하기
  - 편의점까지 걷기
  - 밀린 문자 1개 답장
  - 책상 위 5개 물건 치우기
  - 10분 산책
  - 병원 예약 확인
  - 가족에게 짧은 안부 보내기

### 7.4 가치 기반 활동 스케줄링

- 가치 영역:
  - 건강
  - 관계
  - 성장
  - 일/학업
  - 돌봄
  - 즐거움
  - 정리/안정
  - 영성/의미
- 사용자는 `내가 회복하고 싶은 삶의 방향`을 고른다.
- 앱은 가치와 연결된 작은 행동을 제안한다.

### 7.5 회피 패턴 분석

- 회피 트리거:
  - 피곤함
  - 실패 예상
  - 사람 만남 부담
  - 완벽주의
  - 몸이 무거움
  - 시작이 어려움
  - 불안
  - 수치심
- 회피 후 단기 이득과 장기 비용을 기록한다.
- 앱은 회피를 비난하지 않고 `회피가 보호하려던 것`과 `회피 때문에 잃은 강화 기회`를 분리해서 보여준다.

### 7.6 외래용 요약

의사에게 보여줄 30초 요약:

- 이번 주 실행률
- 가장 잘 맞은 활동 3개
- 가장 회피가 컸던 상황 3개
- 숙달감이 오른 활동
- 즐거움이 오른 활동
- 수면·활동 리듬 변화
- 자살위험 또는 급격한 악화 알림

## 8. 안전 설계

### 8.1 고위험 분기

다음이 확인되면 앱은 일반 활동 처방을 중단하고 임상가 연락/응급 안내를 우선한다.

- 자살사고, 계획, 의도, 최근 자해
- 조증/경조증 의심: 수면욕구 감소 + 에너지 증가 + 과활동/충동성
- 정신병적 증상
- 급성 물질 문제
- 심각한 식사·수면 붕괴

자살위험이 확인되는 경우 임상적으로는 보건소 자살예방사업인 **생명존중사업** 의뢰 권고를 포함한다.

### 8.2 문구 원칙

- 금지: “우울증을 치료합니다”, “완치”, “효과 보장”
- 허용: “진료 사이의 행동 실천을 돕습니다”, “활동과 기분의 관계를 기록합니다”, “작은 행동 계획을 세웁니다”
- 초기 MVP는 의료기기 효능 표현을 피한다.

## 10. 화면 구성 초안

### 탭 1. Today

- 오늘의 작은 행동 1–3개
- 난이도 조절
- 시작 버튼
- 완료 후 숙달감/즐거움 체크

### 탭 2. Plan

- 가치 영역 선택
- 활동 라이브러리
- 주간 활동 스케줄
- 의사가 처방한 활동 표시

### 탭 3. Log

- 시간대별 활동 기록
- 기분·에너지 변화
- 회피 충동 기록

### 탭 4. Pattern

- 잘 맞는 활동
- 피해야 할 과부하 패턴
- 반복 회피 상황
- 숙달감 vs 즐거움 매트릭스

### 탭 5. Clinic

- 외래 요약 카드
- 위험 신호
- 다음 진료 때 이야기할 질문
- PDF/스크린샷 공유 후보

## 11. 개인화 로직

### MVP 규칙 기반

- 실행률이 낮으면 활동 난이도를 낮춘다.
- 숙달감이 높은 활동은 반복 후보로 올린다.
- 즐거움은 낮지만 숙달감이 높은 활동은 회복 기반 활동으로 분류한다.
- 회피 충동이 높은 활동은 더 작은 단계로 쪼갠다.
- 오전 실행률이 높으면 오전에 배치한다.
- 수면이 나쁜 날은 `2분 행동` 위주로 줄인다.

### 후속 단계

- contextual bandit 또는 강화학습 기반 활동 추천
- wearable 기반 에너지·수면·활동량 반영
- GenAI 코치: 활동 쪼개기, 자기비난 문장 재구성, 외래 요약 문장화
- 개인별 강화원 모델 구축
